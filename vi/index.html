Trang chủ Tài liệu GAP

Graph Agent Protocol (GAP) là cổng gateway GraphQL định kiểu chặt chẽ kèm tầng quản trị zero-trust viết bằng Rust (32 crates phân tầng). Hợp nhất OpenAPI REST, SQL, GraphQL, gRPC, CLI, đồ thị mã nguồn AST, MCP server và agent A2A sau một giao diện lũy tiến thống nhất.

Bạn sẽ nắm được gì

  • Kết nối hàng trăm công cụ mà không làm phình ngữ cảnh LLM (chỉ 651 tokens thay vì 203.421 tokens).
  • Dập tắt lỗi vòng lặp N+1 qua gom lô DataLoader (INV-18) và snapshot bất biến ArcSwap.
  • Cưỡng chế bảo mật mặc định từ chối Cedar, chống rug-pull mô tả tool và chặn SSRF qua EgressGuard.
