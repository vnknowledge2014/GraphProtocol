Khởi chạy Nhanh (10 phút)

Làm theo 4 bước ngắn dưới đây để khởi chạy siêu đồ thị mẫu Walking Skeleton — ghép nối cửa hàng REST OpenAPI (shop) với máy chủ MCP (notes) trong đúng một truy vấn GraphQL.

Bạn sẽ nắm được gì

  • Kiểm tra cấu hình an toàn bằng gap config check và gap doctor.
  • Khởi chạy hai upstream mẫu REST + MCP và tiến trình gap serve.
  • Thực thi câu truy vấn gộp dữ liệu từ cả hai nguồn trong một request duy nhất.

Chuẩn bị Trước khi Chạy

  • Binary gap đã biên dịch (từ bản phát hành hoặc chạy ./dist/build-reproducible.sh --offline tạo ra ./target/dist/gap).
  • Python 3.10+ để chạy hai dịch vụ giả lập mẫu trong examples/walking-skeleton/fixtures/.

Bật nhanh ngay trên Trình duyệt

Nếu bạn đang mở cổng web cục bộ qua python3 web/serve.py --port 8787, bạn có thể nhấn đúng 1 nút trong trang Phòng Lab Thực hành để tự bật toàn bộ các tiến trình này.

Tạo mới Workspace từ đầu?

Bạn có thể khởi tạo nhanh thư mục dự án mẫu 5 tệp bằng lệnh ./target/dist/gap init my-gateway rồi chỉnh gap.toml.

Hướng dẫn Từng bước

  1. 1

    Kiểm tra hợp lệ tệp cấu hình

    Chạy kiểm tra tĩnh với examples/walking-skeleton/gap.toml. GAP từ chối khởi động ngay nếu thấy trường lạ, bí mật ghi trần không qua biến môi trường hoặc thiếu tệp spec:

    • Lưu ý: Cả hai lệnh trả về mã thoát 0 (OPS-044). Khóa API dev-agent được lưu bằng mã băm BLAKE3 trong TOML.
  2. 2

    Khởi chạy hai máy chủ upstream mẫu

    Bật giả lập REST API trên cổng 9101 và máy chủ MCP trên cổng 9102:

  3. 3

    Khởi chạy Cổng GAP Gateway

    Chạy lệnh gap serve trỏ tới cấu hình Walking Skeleton:

    • Kiểm tra sẵn sàng: GET http://127.0.0.1:8080/readyz trả HTTP 200 ({"status":"ready","generation":1}) ngay khi thế hệ snapshot 1 được nạp xong.

    Gửi truy vấn gộp liên nhánh đầu tiên
