## 5. Known Limitations (`0.1.0-rc.1`)

1. **Default Routing (`RTE-044`, `INV-17`):** Shipped `laya-candle:f32` model did not meet `G-S1`; gateway ships in deterministic `BASELINE_FALLBACK` mode (`0.9524` test top-1, `0.887 ms` p95). Neural S1 routing remains opt-in (`[router]`) after online SHA-256 verification and environment-specific calibration.
2. **Columnar Wire Encoding (`GQL-003`):** Internal `ColumnarTable` codec exists (`crates/gap-exec/src/columnar/`), while `@format(as: COLUMNAR)` wire activation is closed for `1.0-RC` because `GAP-Bench` measured `< 20%` large-list suite savings ([`x1-columnar.md`](../decisions/x1-columnar.md)).
3. **Optional SurrealDB Store (`ADR-020`, `OPS-042`):** `--features store-surreal` compiles GAP's thin transport & schema module cleanly (`0` BSL crates in default `Cargo.lock` or default builds); live SurrealDB 3.x server tests require deploying a separate BSL-1.1 SurrealDB instance.
4. **Local Sandbox & Platform Scope (`SEC-070`):** Production strict kernel isolation (`bwrap` / `nsjail` + Landlock/seccomp) targets Linux (`docker` / Colima Ubuntu host); macOS uses Seatbelt (`sandbox-exec`, deprecated by Apple) for local development/testing.
5. **Remaining Wall-Clock Endurance & Optional API Suites Pre-`v1.0.0`:** Continuous `72 h` soak (`259200 s`), `24 h`/target `libFuzzer` campaigns (`86400 s`), full-workspace `ASan`/`TSan`/`miri`/`cargo-mutants` sweeps, live Alertmanager webhook firing, and optional live frontier-LLM API key benchmarks await pre-GA execution per `ADR-021`.
