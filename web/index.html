GAP Documentation Hub

Graph Agent Protocol (GAP) is an open-source, typed GraphQL-profile gateway and zero-trust governance runtime built in Rust across 32 layered crates. Unify OpenAPI REST services, SQL databases, GraphQL subgraphs, gRPC services, CLI tools, codebases, MCP servers, and A2A peers behind one progressive interface.

What you'll learn

  • Connect heterogeneous tools without dumping 200k+ schema tokens into every LLM prompt.
  • Eliminate agent N+1 round-trips using DataLoader join batching and wait-free ArcSwap snapshots.
  • Enforce default-deny Cedar authorization, rug-pull description pinning, and SSRF egress guards.

The 4 Problems GAP Solves

📦

Context Explosion

1,000 flat JSON tools = 203,421 tokens before the user asks anything. GAP holds constant at 651 tokens.

🔁

N+1 Agent Waterfalls

Without a join planner, agents loop per-row: fetch customer → loop orders → fetch notes. Each loop burns latency and tokens.

🎭

Mutable Descriptions (Rug Pulls)

Upstream edits a tool description after approval to inject hidden instructions. Flat clients forward poisoned text to the LLM.

🔓

Probabilistic Auth Leaks

Neural classifiers on the access-control path introduce bypass risk. Authorization must be deterministic code, not ML.

Core Platform Capabilities

Three-Plane Architecture

Zero-ML hot execution (15 ns ArcSwap pinning, own pure-Rust AVL OrdMap) separated cleanly from discovery and control.

Progressive Disclosure (651 Tokens)

Replace linear schema growth (203,421 tokens at N=1,000) with constant 5-tool MCP discovery (L0 -> L1 -> L2).

6 Native Graph Connectors

Declarative OpenAPI, SQL, GraphQL, gRPC, sandboxed CLI, and tree-sitter Code AST adapters gated by Propose-Not-Activate.

MCP, A2A & AG-UI Facades

Serve MCP 2026-07-28, A2A v1.0 durable tasks, and AG-UI v1.0 /ag-ui SSE approval interrupts from one binary.

Zero-Trust Agent Governance

Cedar policies, T0/T1/T2 isolation, <gap:untrusted> escaping, DriftMonitor rug-pull freeze, EgressGuard SSRF, and BLAKE3 audits.

HTTP/3 QUIC & System-1 Routing

5,013 req/s multiplexed QUIC (2.36 ms p95, 0-RTT off) alongside 95.24% top-1 baseline routing and INV-17 fallback.

Measured Performance & Security Highlights

❌ Without GAP (Direct-MCP)

  • 203,421 tokens just to list 1,000 tools
  • Agent loops N+1 per customer/order/note
  • Tool descriptions mutable after approval
  • Neural classifier on the auth hot-path

✅ With GAP

  • 651 tokens constant (5 static tools)
  • Declarative @join + DataLoader batching
  • BLAKE3 desc_hash pinning freezes drift
  • Deterministic Cedar default-deny policies
