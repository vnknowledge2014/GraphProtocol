System-1 Routers & HTTP/3 QUIC

GAP decouples optional System-1 neural decision models (@receptron/laya, TypeSafe Jev, Google gemini-decision-1) from the deterministic runtime, and delivers dual-stack HTTP/2 + native HTTP/3 over QUIC with 0-RTT disabled against replay attacks.

What you'll learn

  • Why GAP ships in BASELINE_FALLBACK routing mode rather than uncalibrated neural weights (G-S1).
  • Configure optional [router] decision providers with egress allowlists and secret redaction.
  • Enable native HTTP/3 QUIC (RFC 9114) with fail-closed prod TLS verification.

INV-17 Fail-Open Safety

If any configured external System-1 provider (@receptron/laya, TypeSafe jev /v1/systemone, or Google gemini_decision_1) times out, returns invalid output, or is turned off, discovery falls back seamlessly to the deterministic baseline router while authorization remains untouched.

Dual-Stack HTTP/2 + HTTP/3 over QUIC (OPS-005, ADR-026)

Configured cleanly in gap.toml, gap-transport serves HTTPS/TCP (HTTP/1.1 + HTTP/2 with Alt-Svc: h3=":8443"; ma=86400) and UDP QUIC (quinn + h3, TLS 1.3 ALPN h3) on the same runtime:

  • Replay Immunity: max_early_data_size = 0 disables QUIC TLS 1.3 0-RTT early data everywhere so replayed packets can never trigger mutations twice.
  • Fail-Closed prod Guard: Booting with profile = "prod" and http3_listen without explicit tls_cert_secret / tls_key_secret refuses to start; under profile = "dev", omitting TLS secrets generates an ephemeral self-signed TLS 1.3 certificate automatically.
  • Measured Local Benchmark: 5,013.1 req/s over multiplexed QUIC (1.626 ms p50 / 2.364 ms p95 / 0 errors) alongside 1,063.6 req/s TCP HTTP/1.1+2 (11.544 ms p95).
