MCP, A2A & AG-UI Facades

One running GAP gateway simultaneously serves three open AI interoperability protocols—MCP 2026-07-28, Agent2Agent (A2A v1.0), and AG-UI v1.0 SSE—without asking existing host clients to rewrite their protocol stacks.

What you'll learn

  • How all 5 static MCP meta-tools map onto progressive GAP-QL discovery and guarded mutations.
  • Expose an A2A Agent Card with durable SQLite task leases and cycle detection (INV-20).
  • Stream structured AG-UI v1.0 events and Cedar human-in-the-loop approval interrupts over SSE.

Three-Axis Interoperability Stack

Think of GAP's facades as compatibility translators in front of one core engine: vertical tool hosts speak MCP, peer agent networks speak A2A, and browser/copilots speak AG-UI—all sharing the exact same immutable snapshot and Cedar policy checks.

Vertical Tool Facade: MCP 2026-07-28 (651 Tokens)

Five static MCP meta-tools exposed by adapters/gap-mcp
Tool NameBehaviorPolicy / Safety Effect
gap_searchHybrid BM25 + HNSW search across active branches (L1).Pre-filtered by Cedar visibility bitset (INV-05).
gap_describeBranch overview (L0) or exact SDL type hydration (L2).Serves only approved desc_hash text (INV-08).
gap_queryExecutes read-only batched GAP-QL queries.Enforces read-only annotation + PlanCache TenantId key.
gap_mutateExecutes state-changing mutations.Requires @sideEffect + Cedar two-person approval when irreversible.
gap_taskSubmits, polls, or cancels long-running A2A tasks.Persists FSM transitions in SQLite before emission (INV-13).

Horizontal A2A v1.0 & Frontend AG-UI v1.0

  • A2A v1.0 Task Binding (adapters/gap-a2a): Builds durable 8-state asynchronous task lifecycles backed by SQLite leases with monotonic hop counters that fail closed on delegation loops (GAP_LOOP_DETECTED, INV-20).
  • AG-UI v1.0 Event Streaming (adapters/gap-agui): Exposes POST /ag-ui SSE streaming typed events (RUN_STARTED, STEP_STARTED, TOOL_CALL_*, STATE_SNAPSHOT, RUN_FINISHED). When Cedar requires human confirmation on an IRREVERSIBLE mutation, AG-UI pauses via a native RUN_FINISHED interrupt and resumes cleanly after approval.
