Graph Agent Protocol (GAP): Unifying Typed Discovery, Batched Federation, and Zero-Trust Governance for AI Agents

Mike (GAP Project Lead)
Reference Release v0.1.0-rc.1 · November 16, 2026 · Apache-2.0
Abstract. We introduce Graph Agent Protocol (GAP), a strongly typed GraphQL-profile gateway unifying APIs, SQL stores, gRPC/GraphQL services, codebases, MCP servers, and A2A tasks across three separated architectural planes: (1) a Zero-ML deterministic execution plane with Cedar authorization, tenant-scoped planning, batched DataLoader joins, and wait-free immutable snapshot pinning; (2) a three-level progressive discovery plane holding static MCP tools/list cost invariant at 651 tokens across N=10..1,000 tools; and (3) a zero-trust control plane preventing MCP rug pulls via description-hash drift freezes, DNS-pinned egress SSRF defense, OS sandboxing, and BLAKE3 hash-chained audit logs. Implemented across 31 Rust crates and verified across 2,481 spec-trace markers, GAP reduces cross-branch token cost at N=1,000 by 99.0% uncached (93.5% cached) and code-graph context by 119.3x-208.7x, cold-starts in 1197.4 ms at 9.16 MiB idle RSS, sustains 1889.0 req/s with 0 errors at 6.36 ms p95, and recovers from OS SIGKILL in 19.24 ms.

1. Introduction & Threat Model

AI agent stacks split tool invocation (Anthropic MCP) from horizontal agent tasks (Google A2A). Publishing flat MCP JSON Schemas inflates prompts linearly from 1,904 tokens at N=10 to 203,421 tokens at N=1,000, induces N+1 client join loops, and exposes hosts to descriptor rug pulls documented in arXiv security audits (arXiv:2506.02040, arXiv:2508.14925, arXiv:2512.06556). GAP enforces 20 normative invariants (INV-01..INV-20) and zero ML on the typed execution hot path (ARC-002).

2. Protocol & Security Controls

GAP-QL is a strict GraphQL profile parsed by apollo-compiler behind a constant 5-tool MCP 2026-07-28 facade (gap_search, gap_describe, gap_query, gap_mutate, gap_task) and A2A v1.0 task APIs. All branches carry explicit trust tiers (T0 Ed25519 signed, T1 admin-approved, T2 untrusted wrapped in escaped <gap:untrusted> tags). Mutations require Cedar verification and verified @sideEffect classifications. Background DriftMonitor freezes branches immediately to BranchStatus::Drift upon unapproved description changes (SEC-082).

4. RouteBench & Live Runtime Evaluation

On RouteBench (n=48 test + 72 held-out), un-finetuned Candle weights (laya-candle:f32) achieve 14.29% debiased top-1 at 73.85 ms p95, whereas GAP's deterministic lexical+structural baseline reaches 95.24% test / 97.22% held-out top-1 in 0.887 ms—justifying fail-safe BASELINE_FALLBACK deployment (INV-17).

In live release-binary drills (bench/results/ga_local/report.json), GAP boots to HTTP 200 /readyz in 1197.43 ms, occupies 9.16 MiB idle RSS (15.84 MiB post-load), processes 800 mixed requests across 8 threads at 1889.0 req/s (3.912 ms p50 / 6.356 ms p95 / 9.481 ms p99, 0 errors), and restores verified traffic after SIGKILL in 19.24 ms.
