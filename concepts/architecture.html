Three-Plane Architecture

GAP guarantees sub-microsecond snapshot swaps and deterministic security by strictly prohibiting machine-learning dependencies on its execution plane (ARC-002).

What you'll learn

  • How Plane 1 (Execution), Plane 2 (Discovery), and Plane 3 (Control) isolate responsibilities.
  • Why every request stays pinned to one immutable snapshot via ArcSwap and pure-Rust AVL OrdMap.
  • Explore every component interactively using the 10-Node Architecture Inspector.

Strict Plane Separation

Notice the hard compiler boundary enforced by tools/check_layers.py: crates in the hot execution plane (gap-exec, gap-plan, gap-transport, gap-snapshot, gap-balance) fail CI immediately if any ML crate ever enters their dependency tree.

Wait-Free Request Pinning & Memory Control

  • Zero Lock Across .await (INV-02): Inbound requests execute one atomic ArcSwap::load (~15 ns) and hold that immutable Arc<Snapshot> until completion.
  • Owned Pure-Rust AVL OrdMap: Replaced the unmaintained im crate (RUSTSEC-2026-0097 ecosystem risk), eliminating 100% of unsafe blocks in snapshot state structures and delivering 0 RUSTSEC advisories.
  • Automatic 60s RollbackWatcher (INV-16): Publication swaps pre-warm top-100 plans, drop old snapshots on a background thread, and revert automatically if error rates spike across 200+ samples.
