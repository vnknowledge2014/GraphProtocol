10-Minute Quickstart

Follow these four steps to run the Walking Skeleton supergraph—combining a REST OpenAPI store (shop) and an MCP server (notes)—and query both in one typed request.

What you'll learn

  • Validate configuration files fail-closed with gap config check and gap doctor.
  • Boot the local REST + MCP sample fixtures alongside gap serve.
  • Send your first cross-branch GraphQL query joining both upstream sources.

Prerequisites

  • Built gap binary (from release assets or ./dist/build-reproducible.sh --offline at ./target/dist/gap).
  • Python 3.10+ (for the built-in sample REST and MCP fixtures under examples/walking-skeleton/fixtures/).

Zero-Setup Browser Shortcut

Already running python3 web/serve.py --port 8787? You can boot these exact fixtures with one click inside the Interactive Lab.

Step-by-Step Setup

    Inspect and validate the configuration

    • Check output: Both commands exit 0 (OPS-044). Notice the dev-agent API key uses a SHA/BLAKE3 hash—no plaintext secret is ever stored in TOML.

    Start both upstream fixtures

    Boot the GAP Gateway

    Start gap serve pointing at the walking-skeleton configuration:
