# WP-M4-04 Step Breakdown — Enricher (`NullEnricher`, Constrained `LlmEnricher`, Caching, Golden Set `G-E1`)

**Refs:** `ING-030`, `ING-031`, `ING-032`, `ING-033`, `ING-034`, `ING-035`, `SEC-042`  
**Owns:** `crates/gap-ingest/src/enrich/**`, `bench/enrichment/**`

## 2–5 Minute Steps
1. **Types & `NullEnricher` (`crates/gap-ingest/src/enrich/mod.rs`):** Define `Enricher`, `EnrichmentConfig`, `EnrichmentCacheKey`, `EnrichmentCache`, `EnrichmentStatus`, `EnrichmentOutput`, `EnrichError`, and `NullEnricher`.
2. **Privacy, Redaction & Delimited Prompt (`ING-032`, `ING-033`, `SEC-042`):** Implement `redact_sensitive_text`, `build_isolated_enrichment_prompt` (scrubbing secrets, internal hosts, RFC1918 IPs, defaults/examples; enforcing `max_prompt_bytes` cap and `<untrusted_branch_data>` delimiter neutralization).
3. **Constrained Validation & `ING-031`/`ING-034` Guards:** Parse candidate LLM JSON output via `parse_bounded_json`, reject unexpected keys and authority/security mutations (`ING-031`), reject hallucinated operations/types/fields (`ING-034`), tag proposed joins as `JoinEvidence::Llm`, and verify post-merge `ING-031` invariants.
4. **Retries, Fallback & Caching (`ING-030`, `ING-035`):** Implement `LlmBackend`, `HeuristicConstrainedBackend`, and `LlmEnricher` enforcing `allow_cloud_enrichment` default `false`, caching by `(source_hash, enricher_id, prompt_version, model_id)`, retrying up to 2 times on malformed output, and falling back to `NullEnricher` with `enrichment_label = "degraded"` and `auto_activate_allowed = false`.
5. **Unit Tests:** Cover `ING-030`..`ING-035` and `SEC-042` with explicit `// spec:` markers.
6. **Golden Set Benchmark (`bench/enrichment/src/main.rs`):** Author 32 public domain specs + adversarial fixtures, verify via Gate `G4` (`evaluate_join_g4`), compute Gate `G-E1` metrics, and support `--offline-fixtures --check-gate`.
7. **Verification & Handoff:** Run `cargo fmt --check`, `cargo clippy`, `cargo nextest`, `cargo run -p enrichment-bench --offline -- --offline-fixtures --check-gate`, Python gates, update status, write handoff, commit, and merge `--ff-only`.
