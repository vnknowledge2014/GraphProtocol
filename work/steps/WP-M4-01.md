# Step Plan: WP-M4-01 (`gap-ingest` foundations: CISG, Extractor trait, worker process framework)

- **Branch:** `wp/WP-M4-01`
- **Spec refs:** `ING-010`, `ING-011`, `ING-012`, `ING-020`, `ING-070`, `ING-071`
- **Owns:** `crates/gap-ingest/src/cisg/**`, `crates/gap-ingest/src/fetch/**`, `crates/gap-ingest/src/worker/**`, `crates/gap-ingest/src/lib.rs`

## Steps
1. **CISG & `Extractor` trait (`crates/gap-ingest/src/cisg/mod.rs`):**
   - Implement `UntrustedText` (`text`, `sanitized`, `lint: LintStatus`, `hash`) stripping bidirectional overrides, control characters, and flagging untrusted prompt-injection markers so only `sanitized` flows downstream (`ING-020`).
   - Implement `Cisg`, `SourceRef`, `ExtractorInfo`, `TypeDef`, `FieldDef`, `TypeRef`, `ArgDef`, `Example`, `Pagination`, `OperationDef`, `KeyDef`, `FieldRef`, `JoinCardinality`, `JoinEvidence`, `CandidateJoin`, `DocBlob`, and structured `CisgValue` using `gap_core::snapshot::{OpKind, Protocol, SideEffectLevel}`.
   - Implement deterministic `canonicalize()`, JCS canonical JSON encoding, and SHA-256 `cisg_hash()` / `source_hash` (`ING-010`).
   - Define `Extractor`, `SourceHandle`, `ExtractLimits`, and `ExtractError` enforcing size/depth/item caps without panicking (`ING-011`, `ING-012`).
2. **Guarded fetcher (`crates/gap-ingest/src/fetch/mod.rs`):**
   - Define `SourceFetcher`, `FetchLimits`, `FetchedSource`, `FetchError`, and `DenyAllSourceFetcher` denying all network fetches by default until `EgressGuard` lands (`ING-011`).
3. **Worker isolation pool (`crates/gap-ingest/src/worker/mod.rs`):**
   - Define `WorkerLimits`, `WorkerPoolConfig`, `WorkerMetrics` (`active_for_tenant`, `gap_ingest_backlog`), `WorkerReport`, `WorkerOutcome`, and `WorkerPool` supporting both in-process isolated execution (`catch_unwind` + timeout + per-tenant concurrency cap <= 2) and scrubbed-env subprocess execution (`run_command_isolated` with timeout kill + bounded output caps) (`ING-070`, `ING-071`, `ING-012`).
4. **Re-exports & verification (`crates/gap-ingest/src/lib.rs`):**
   - Expose curated public exports, add unit/integration tests tagged `// spec: ...` for `ING-010`, `ING-011`, `ING-012`, `ING-020`, `ING-070`, `ING-071`, run `fmt`, `clippy`, `nextest`, `cargo test`, and Python repo checks (`check_layers`, `wp validate`, `check_refs`, `spec_trace`), then write handoff and merge to `main`.
