# WP-M1-11 steps — `gap-ngc-openapi` v0: OpenAPI 3.x read connector, auth, in-memory fixture REST service, NGC kit run

Assumptions
- A1 Scope is `WP-M1-11` (`work/work-packages.toml`, `work/context/m1-11-brief.md`): JSON OpenAPI `3.0.x`/`3.1.x` documents only, `GET` operations only (non-`GET` methods and unsupported parameter styles are recorded in `ExtractionReport.skipped` and never exposed as `MUTATION`), local `#/...` `$ref` pointers only, and `servers[]` recorded in the report and never followed.
- A2 Upstream I/O is abstracted behind `pub trait Upstream: Send + Sync + 'static` (`OpenApiConnector<U: Upstream>`, no `dyn`). `FixtureService` implements `Upstream` directly for deterministic in-memory tests without sockets or child processes; `HttpUpstream` wraps `reqwest` (`default-features = false`, no TLS, no redirects, `Response::chunk()` streaming cap, no `Accept-Encoding`); socket tests carry `#[ignore = "needs loopback sockets"]`.
- A3 Credentials resolve through a connector-local `CredentialSource` trait (`gap-sec::vault` is an empty stub until `WP-M6-07`) returning `gap_core::secret::SecretString`. `https://` base URLs fail closed at construction (no TLS backend in v0), and non-loopback `http://` with credentials fails closed unless `allow_insecure_upstream = true` (`CMP-031`, `INV-15`).
- A4 All time-sensitive retry and deadline behavior uses `tokio::time` and `CallScope` (`scope.deadline`, `scope.cancel`), so tests run deterministically under `#[tokio::test(start_paused = true)]` without wall-clock sleeps.
- A5 In the frozen NGC kit (`crates/gap-conformance/src/ngc_kit/checks/mutate.rs`), `mutate.dry_run` checks `kit.profile.mutate` before `capabilities.dry_run` in order to probe `NGC-031` ("unadvertised dry run fails `UNIMPLEMENTED`" -> `Outcome::Pass`). `conformance/ngc/openapi.kit.toml` therefore supplies `[mutate] operation = "create_order"` (which `OpenApiConnector` rejects with `UNIMPLEMENTED`), so `mutate.idempotency` is `Skip(NotApplicable)`, `mutate.dry_run` is `Pass`, and zero checks are `NotCovered`.

Rejected simpler alternative: parse OpenAPI documents via `openapiv3` / `utoipa` or `serde_json::from_slice::<Value>` directly and call `reqwest::Client::get(format!("{base}{path}"))`. Rejected because `serde_json::Value` without a streaming depth/item visitor allows unbounded item allocation on hostile inputs (`ING-012`), `format!` URL concatenation permits path-traversal/query/host-override escapes (`CMP-030`), and no OpenAPI crate is in the locked offline dependency set.

Risks
- R1 Hostile OpenAPI documents (deep nesting, wide objects, `$ref` cycles/chains, multi-MiB payloads) exhausting memory or stack. Mitigation: check `max_bytes` before parsing, deserialize through a custom `DeserializeSeed` visitor tracking `depth <= max_depth` and `items <= max_items`, and bound `$ref` expansion by `max_ref_hops` + cycle stack + expanded node budget.
- R2 Parameter injection (`..`, `/`, `%2e`, `?`, `#`, CR/LF/NUL) escaping path segments, query keys, headers, or `base_url` origin (`CMP-030`). Mitigation: percent-encode all non-RFC-3986-unreserved bytes in path/query slots, additionally encode `.` and `..` path segments (`%2E`, `%2E%2E`) and reject empty path parameters, reject control characters in header values, and verify origin preservation in `HttpUpstream`.
- R3 Upstream secret or body leakage in `Debug`, `tracing`, `Describe`, `Complete`, or `NgcErrorInfo` (`INV-15`, `NGC-061`). Mitigation: `SecretString` redaction, fixed diagnostic strings on `401`/`403` and upstream errors (never echoing upstream bodies or URLs), and explicit secret-canary tests across logs/errors/wire responses.
