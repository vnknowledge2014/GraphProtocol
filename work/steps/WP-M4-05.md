## Steps

1. Define gate framework and canonical verification report types (`ING-001`, `ING-040`):
   - `GateId`, `GateKind`, `GateFailAction`, `AdminAck`, `GateOutcome`, `GateResult`, `GenerationDiff`, `VerificationReport`, and `can_activate_join` (`ING-040`).
   - Deterministic canonical JSON serialization using `crate::cisg::CisgValue`.
   - Enforce that hard gates (`G1`, `G2`, `G3`, `G6`, `G7`) cannot be overridden by `AdminAck`, while soft gates (`G9`) accept audited `AdminAck`.
2. Implement G1 Schema validity (`GQL-004`, `ING-001`):
   - Validate CISG identifiers, reserved `__` / GAP built-in type / root field collisions (`GQL-004`), uniqueness of types/fields/operations/args, and resolvable `TypeRef`s.
   - Synthesize/validate GraphQL branch SDL and compose against GAP built-ins via `gap_ql::schema::{validate_branch_sdl_reserved_names, compose_supergraph_sdl}`.
3. Implement G2 Type coercion (`spec/05-ingestion.md` §5):
   - Table-driven `ScalarKind` coercion matrix (`SameScalar`, `Id <-> String`, `Uuid <-> String(uuid)`, `Int <-> Int64` / `Int <-> String(numeric)` only with explicit `coerce`, `Int <-> Boolean` and `Float <-> Int` forbidden) plus nullability check.
   - Drop invalid `CandidateJoin` entries in place and report `CandidateDropped`.
4. Implement G3 Key lookup (`spec/05-ingestion.md` §5):
   - Verify each candidate join's RHS key is a declared unique/PK in `cisg.keys` or has sketch `uniqueness_ratio >= 0.999`, and that RHS supports batched resolution (`foreach` / `IN`).
5. Implement G6 Boundedness (`GQL-042`, `spec/05-ingestion.md` §5):
   - Map joins into `gap_core::joingraph::{JoinGraph, JoinEdge, JoinStatus, ...}`, validate cycles via `JoinGraph::validate_join_cycles`, enforce `max_depth` in `1..=16` and per-hop fanout caps.
6. Implement G7 Security lint stub & G9 Resource budget (`spec/05-ingestion.md` §5):
   - `SecurityLintHook` trait + `DefaultSecurityLintStub` checking `UntrustedText::lint`, `hash` format, hidden/bidi controls, SSRF URL hazards, and T0/T1 side-effect completeness.
   - G9 resource budget check with optional audited `AdminAck`.
7. Add table-driven & unit tests matching `test(gate)` tagged `// spec: ING-001, ING-040, GQL-004, GQL-042`, run `fmt`, `clippy`, `nextest`, and repo gates.
