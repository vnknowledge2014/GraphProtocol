# WP-M3-01 steps — gap-balance: telemetry slots, time-decayed EWMA, in-flight guard, circuit breaker, retry budget, P2C selection

- **Assumptions:**
  1. All builds, tests, lints, docs, and benchmarks run strictly offline against `.local/vendor` via the existing git-ignored `.cargo/config.toml` (`--offline`, never modified or staged). Cargo commands run in the workspace sandbox using a temporary `CARGO_HOME` cleaned up before finishing; Git mutating commands stage explicit file paths only and preserve `.git/config` author identity; Python scripts run with `PYTHONDONTWRITEBYTECODE=1 python3 -B`.
  2. `crates/gap-balance/Cargo.toml` follows `work/context/m3-01-design.md` §2 verbatim with single-line sorted `workspace = true` dependencies (`ARC-001`), `[target.'cfg(gap_shuttle)'.dependencies] shuttle.workspace = true`, `[lib] bench = false`, three `[[bench]]` targets (`update`, `selection`, `percentiles`) with `harness = false`, and `[lints.rust] unexpected_cfgs = { level = "warn", check-cfg = ["cfg(gap_shuttle)"] }`. `loom` is not used.
  3. All public API names, signatures, thresholds, tie-breaking rules, memory-ordering discipline, test matrices, and benchmark targets follow `spec/04-routing.md` §8 (`RTE-070`..`RTE-093`), `spec/01-architecture.md` (`ARC-001`, `ARC-002`, `ARC-006`, `INV-02`, `INV-09`, `INV-10`), `spec/03-ngc.md` (`NGC-070`, `NGC-072`), `spec/08-operations.md` (`OPS-020`), `docs/01-DECISIONS.md` (`ADR-006`, `ADR-011`, `ADR-025`), and `work/context/m3-01-design.md`.
  4. `tools/spec_trace.py` validates `spec: <ID>` comments in `crates/**` strictly against requirement IDs defined in `spec/*.md`. Every test carries `// spec: <SPEC_ID>` using `spec/*.md` IDs only and places `ADR-*` citations in parentheses afterwards so `spec_trace.py` reports `0 unknown test IDs`.
- **Rejected simpler alternative:**
  - *Alternative A:* Protect `DecayedEwma`, `Breaker`, or `TelemetrySlot` with a `Mutex` or `RwLock`. Rejected because `INV-02` and `ARC-006` forbid locks and allocations on the request hot path; packed lock-free CAS words (`AtomicU64` / `AtomicU32`) routed through `src/sync.rs` allow zero-allocation hot-path updates and deterministic `shuttle` schedule exploration.
  - *Alternative B:* Store `TelemetryRegistry` slots in a single flat `Vec<Arc<TelemetrySlot>>` inside `ArcSwap` or behind an `RwLock<HashMap<..>>`. Rejected because copying the entire flat vector on every `register` is `O(n)` and locking on `get` violates `INV-02`; a two-level copy-on-write slab of 256-slot chunks (`Vec<Arc<Chunk>>` inside `ArcSwap`) keeps `get(BranchSlot)` lock-free (`O(1)`, two indexings) and registration copy cost `O(256 + len / 256)` (`RTE-078`).
  - *Alternative C:* Allow `select` / `select_excluding` to call `Breaker::admit` during candidate scoring or allocate a `Vec<usize>` of eligible candidates per call. Rejected because `RTE-079` and `m3-01-design.md` §§4, 6.4, 6.8 require selection to be side-effect-free (never mutating breaker state or probe tallies) and 100% heap-allocation-free on the hot path.
- **Risks:**
  1. Concurrent out-of-order `Now` ticks or `u32` quarter-millisecond wraparound (`~49.7` days) in `DecayedEwma` could corrupt decay exponents or break the 64-thread CAS trail invariant (`RTE-070`, `RTE-077`). Mitigated by modular `u32::wrapping_sub` arithmetic separating `ahead in 1..65_536` (`dt = 0`, keep stored timestamp, commit self-loop CAS), `ahead >= 65_536` or `age * 4 > 5 * half_life_ms` (stale/unknown on read, re-seed on update), and `age == 0` (commit self-loop CAS).
  2. `HalfOpen` probe permits dropped on future cancellation or across `Closed` / `Open` episode boundaries could stall recovery or corrupt a subsequent `HalfOpen` episode (`RTE-085`). Mitigated by packing an episode counter / `closed_gen` tag into the breaker state and bucket words so dropped `ProbePermit`s release their slot only for the matching episode and stale bucket counts never leak into a newly closed window.
  3. `cargo-nextest` is not installed in the sandbox and must not be installed. Mitigated by running `cargo test -p gap-balance --locked --offline` three times in a row plus `shuttle` tests under `--cfg gap_shuttle`, reporting acceptance command 1 as `NOT RUN` under Deviations, and leaving `WP-M3-01` in `doing` state.
