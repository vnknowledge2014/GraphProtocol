# WP-M1-10 steps — `gap-mcp` inbound facade (five static tools, resources, stateless handling, size gate)

Assumptions
- A1 `CMP-006` HTTP authentication (`401 WWW-Authenticate` / `403 insufficient_scope`) and RFC 9728 metadata endpoints belong to `gap-server` (`WP-M1-12` / `WP-M6-01`); `McpFacade` receives an authenticated `RequestContext` per request (`INV-01`) and documents this boundary in `inbound` module rustdoc.
- A2 `rmcp` and external BPE crates (`tokenizers`/`tiktoken`) are not vendored; the thin JSON-RPC wire layer is implemented directly against `third_party/specs/mcp-2026-07-28/` and `mcp-2025-11-25/`, and `G-F1` (`CMP-008`) is enforced in tests via the two conservative in-repo counters (`ceil(bytes/3)` and `<=4`-char alnum runs + non-space punctuation).
- A3 M1 snapshots carry `EmptyElementSearch` (`element_count() == 0`) until `WP-M2-04`/`WP-M2-05`; `gap_search` calls `ctx.snapshot.index.search` when populated and falls back to the deterministic lexical schema matcher emitting a `GAP_DISCOVERY_DEGRADED` warning when empty.
- A4 Legacy `2025-11-25` sessions store only bounded session liveness (`max_sessions`, oldest-first eviction, `tokio::time::Instant` idle TTL) and hold zero request or snapshot state (`INV-01`).

Rejected simpler alternative: supporting only stateless MCP `2026-07-28` and omitting `2025-11-25` session compatibility. Rejected because `CMP-001` mandates serving `initialize` + `MCP-Session-Id` (HTTP) / process-scoped legacy sessions (stdio) during the pre-1.0 compatibility window.

Risks
- R1 Self-authored wire fixtures could encode an implementation misreading: mitigate by authoring `conformance/mcp/tools.expected.json` and `conformance/mcp/*.json` strictly from `spec/09-compat.md` §1 and `third_party/specs/mcp-2026-07-28/` before writing production code.
- R2 `HideT2` leakage through composed type names, counts, or `didYouMean` (`GQL-062`, `INV-05`): mitigate by mapping composed branch type namespaces (`{branch_slug}_*`), `@branch`, and `snapshot.ownership` through `Visibility` and asserting byte-identical outputs with vs without a `T2` branch.
- R3 UTF-8 boundary panic or closing-tag forgery during budget truncation / spotlighting (`GQL-022`, `CMP-007`, `SEC-083`): mitigate with char-boundary clamping and case-insensitive `<gap:untrusted` / `</gap:untrusted>` escaping before wrapping.
