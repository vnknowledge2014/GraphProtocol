     - **A2:** `ErrorCode::AmbiguousField` (`GAP_AMBIGUOUS_FIELD`, `ErrorClass::Composition`, non-retryable, `NgcErrorCode::InvalidArgument`) is added to `gap-core::error`, and existing `ErrorCode::DirectiveIgnored` (`GAP_DIRECTIVE_IGNORED`) moves to `ErrorClass::Composition` and `NgcErrorCode::InvalidArgument` (`ErrorCode::ALL.len() == 48`, matching the 48 distinct codes in `spec/02-gap-ql.md` §10 without touching `spec/`).
     - **A3:** `FieldOwnership` maps every `@branch`-governed field coordinate `(type_name, field)` to `BranchUid` — both branch root fields (`Query.<op>`, `Mutation.<op>`, `Subscription.<op>`) and fields of branch non-root `@branch`-tagged object types (`<ns>_<Obj>.<field>`).
  4. `tools/spec_trace.py` matches `// spec: <ID>` against `spec/*.md` IDs only (`ARC-005`, `ARC-006`, `RUN-003`, `RUN-009`, `RUN-011`, `GQL-004`, `GQL-030`, `GQL-032`, `NGC-011`, `INV-01`, `INV-02`, `INV-09`, `INV-16`); ADR references (`ADR-015`, `ADR-023`) are placed in parentheses after the spec IDs.
- **Rejected simpler alternative:**
  - *Alternative A:* Use `f64::to_string()` or `serde_json::to_string()` for `canonical_json` numbers and `BTreeMap<String, Value>` UTF-8 key order. Rejected because `f64::to_string()` omits scientific notation on `1e21`/`1e-7` (`1000000000000000000000` vs `"1e+21"`, `0.0000001` vs `"1e-7"`) and prints `-0.0` as `"-0"`, while UTF-8 byte order reverses supplementary characters (`U+10000`, UTF-16 `0xD800 0xDC00`) relative to BMP PUA/compatibility characters (`U+E000`, UTF-16 `0xE000`), violating RFC 8785 (`spec/00-conventions.md` §7).
  - *Alternative B:* Emit branch root fields via `ObjectTypeExtension` (`extend type Query { ... }`) in `compose`. Rejected because `apollo-compiler` serializes extensions as separate `extend type Query` blocks in `Schema::to_string()`; merging branch root fields directly onto the single `Query`/`Mutation`/`Subscription` AST definitions produces a clean canonical supergraph SDL where every type appears once.
  - *Alternative C:* Rebuild `im::OrdMap` from scratch in `SnapshotBuilder` instead of delta-updating `current.branches.clone()`. Rejected because rebuilding allocates fresh B-tree nodes and drops internal tree node sharing (`ARC-005`), whereas `im::OrdMap::clone()` + selective `remove`/`insert` preserves internal B-tree nodes and untouched `Arc<BranchDescriptor>` pointers.
- **Risks:**
  1. `apollo-compiler` rejects `__search` and `__metaGraph` in SDL text (`GQL-004`). Mitigated by building and validating the supergraph schema with programmatic `SearchResult`/`SearchHit` AST definitions first, capturing `Composition.sdl` from that valid standalone schema, and then calling `gap_ql::schema::inject_gap_introspection_fields` onto `Composition.schema` before wrapping with `Valid::assume_valid`.
  2. Adversarial branch SDLs (10,000 types, deep list/non-null wrapper chains, 1 MiB descriptions) could overflow the call stack during recursive AST type rewriting. Mitigated by bounding `Type` wrapper recursion (`MAX_TYPE_WRAPPER_DEPTH = 64`) and leveraging `gap_ql::schema::bounded_parser()`.
