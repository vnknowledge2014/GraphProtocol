# Step Plan — WP-M4-03 (Extractors: MCP server and A2A AgentCard)

- **Work Package:** `WP-M4-03`
- **Branch:** `wp/WP-M4-03`
- **Owns:** `crates/gap-ingest/src/extractors/mcp/**`, `crates/gap-ingest/src/extractors/a2a/**`, `fuzz/fuzz_targets/fuzz_extract_mcp.rs`
- **Spec Refs:** `ING-010`, `ING-012`, `ING-020`, `CMP-011`, `CMP-014`, `CMP-020`, `CMP-021`, `CMP-022`

## Steps

1. **Bounded Pure-Rust JSON Parser & Resource Guards (`crates/gap-ingest/src/extractors/mcp/mod.rs`)**
   - Implement `pub(crate) fn parse_bounded_json(bytes: &[u8], limits: &ExtractLimits, started: Instant) -> Result<CisgValue, ExtractError>`.
   - Enforce `max_bytes` (`TooLarge`), `max_depth` (`DepthExceeded`), bounded JSON node budget (`TooManyItems`), `timeout` (`Timeout`), strict RFC 8259 syntax/UTF-8/surrogate/finite-number validation (`Malformed`), without any `serde_json` dependency in `gap-ingest` or unsafe code.
   - Verify with parser unit tests (`extractor_mcp_hostile_json_and_limits`).

2. **MCP Deterministic Extractor (`crates/gap-ingest/src/extractors/mcp/mod.rs`)**
   - Implement `McpExtractor` implementing `Extractor` (`Protocol::Mcp`, `gap-ingest.mcp`).
   - Map MCP `tools` (or wrapped `result.tools`) to sorted `OperationDef`s with sanitized GraphQL-safe names and collision suffixing (`_2`, `_3`, ...).
   - Treat `tool.annotations` (`readOnlyHint`, `destructiveHint`, `idempotentHint`, `openWorldHint`) strictly as untrusted hints (`CMP-011`, `ADR-015`): default classification to `OpKind::Query` unless admin-classified as `Mutation`, keep `side_effect = SideEffectLevel::Unknown` (`idempotent = None`) unless explicit admin trust classification overrides it, and never let `readOnlyHint` relax admin policy.
   - Extract `inputSchema` / `outputSchema` into `ArgDef`s + `TypeDef`s, compute `desc_hash` over canonical RFC 8785 JSON (`CMP-014`), sanitize all free text with `UntrustedText::from_raw` (`ING-020`), emit `McpResource` + `mcp_read_resource` when resources/templates exist (`CMP-011`), and ignore `prompts` (`CMP-011`).
   - Call `cisg.canonicalize()` and assert `ING-010` byte-for-byte determinism across reordered inputs.

3. **A2A AgentCard Extractor & JWS Verification (`crates/gap-ingest/src/extractors/a2a/mod.rs`)**
   - Implement `A2aExtractor` implementing `Extractor` (`Protocol::A2a`, `gap-ingest.a2a`).
   - Validate A2A v1.0 `AgentCard` required fields (`name`, `description`, `version`, `supportedInterfaces` with `JSONRPC` / `GRPC` / `HTTP+JSON`, `capabilities`, `defaultInputModes`, `defaultOutputModes`, `skills[]`).
   - Implement A2A §8.4.1 RFC 8785 JCS canonicalization (excluding `signatures`, retaining explicit optional booleans and required fields, omitting unset optional/empty repeated fields) and RFC 7515 detached JWS verification via `SignatureVerifier` + built-in `TrustedKeyStore` (`HS256` + custom verifier callback).
   - Emit `A2aTaskState` (`CMP-021` 8-state enum + `map_a2a_task_state` rejecting `TASK_STATE_UNSPECIFIED`), `A2aTask`, per-skill `OpKind::Task` `OperationDef`s preserving `AgentInterface.tenant` (`CMP-022`), and `DocBlob`s via `UntrustedText::from_raw` (`ING-020`).

4. **Fuzz Target (`fuzz/fuzz_targets/fuzz_extract_mcp.rs`)**
   - Exercise `McpExtractor` and `A2aExtractor` on arbitrary fuzzer input bytes under strict `ExtractLimits`, asserting panic-free execution and canonical JSON serialization on `Ok(Cisg)` (`ING-012`).

5. **Verification & Handoff**
   - Run `cargo fmt --all -- --check`, `cargo clippy -p gap-ingest --all-targets --offline -- -D warnings`, `cargo nextest run -p gap-ingest --offline`, `tools/check_layers.py`, `tools/wp.py validate`, `tools/check_refs.py`, `tools/spec_trace.py`.
   - Record handoff in `work/handoffs/WP-M4-03.md`, commit, and fast-forward merge `wp/WP-M4-03` to `main`.
