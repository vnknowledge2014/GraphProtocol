# WP-M1-09 steps — gap-mcp outbound connector (an MCP server as a branch)

Implementer: Claude Sonnet 5.5 (the orchestrator, because the usual coder agent was busy on WP-M1-05 on the same working tree). Implementer and reviewer are the
same agent here, so the review is made mechanical: a string-mutation campaign over the connector's own logic, spec-derived wire fixtures, real-child and
real-socket runs of the `#[ignore]` tests, a clean-room offline build (Step 12).

Assumptions
- A1 `rmcp` is not vendored, so the thin JSON-RPC client the work package allows as the alternative is implemented; the ADR addendum text is in the handoff.
- A2 `tools/call` is never retried (MCP has no idempotency); discovery calls retry once on a connection failure.
- A3 Mutation operations (admin-classified tools) are described but `Query`/`Mutate` of them is refused in v0 (`Mutate` stays `UNIMPLEMENTED`).
- A4 `input_required` (MRTR) results are `UPSTREAM_ERROR`, never silently dropped (Task mapping arrives with the task WPs).

Rejected simpler alternative: one transport implementation with the era hard-coded to `2026-07-28`. The compat window (CMP-010) needs the legacy fallback.

Risks
- R1 A fake server written by the same author can share the author's misreading of the spec: the wire fixtures are copied from the pinned spec texts and a real
  child process (a Python stub) plus a real loopback HTTP server exercise the real transports.
- R2 Timing flakes: all tests run on paused tokio time; real-socket and real-child tests are `#[ignore]`.

## Steps (each ends with a command)
1. `error` + `jsonrpc`: sanitised errors, redactor, strict size-capped framing. Run: `cargo test -p gap-mcp outbound::error outbound::jsonrpc`.
2. `transport::stdio`: id-matched replies, cancel notification, bounded lines, EOF. Run: `cargo test -p gap-mcp outbound::transport::stdio`.
3. `transport::http`: JSON and SSE replies, headers per era, reqwest client with https refused. Run: `cargo test -p gap-mcp outbound::transport::http`.
4. `session`: era negotiation, `_meta`, one re-initialisation. Run: `cargo test -p gap-mcp outbound::session`.
5. `map`: tool and resource mapping, SDL, argument validation, result rows. Run: `cargo test -p gap-mcp outbound::map`.
6. `launch` + `config`: allow-list launch policy, sha256 pinning. Run: `cargo test -p gap-mcp outbound::launch outbound::config`.
7. `fake` + `connector`: in-memory fake server, connector with emulated `foreach`. Run: `cargo test -p gap-mcp --test outbound_connector`.
8. Spec-derived wire fixtures. Run: `cargo test -p gap-mcp --test outbound_connector wire`.
9. NGC kit profile and test. Run: `cargo test -p gap-conformance --test ngc_kit_mcp`.
10. `#[ignore]` real-child and real-socket tests. Run: `cargo test -p gap-mcp -p gap-conformance -- --ignored`.
11. Workspace gates. Run: `cargo fmt --all --check && cargo clippy --workspace --all-targets --locked --offline -- -D warnings && cargo nextest run --workspace --locked --offline`.
12. Independent verification and handoff: mutation campaign, clean-room build, `work/handoffs/WP-M1-09.md`.
