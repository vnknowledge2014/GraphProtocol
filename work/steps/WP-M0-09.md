  2. Only the approved dependencies for `WP-M0-09` are declared in `crates/gap-conformance/Cargo.toml` and `crates/gap-testkit/Cargo.toml` using single-line `workspace = true` entries sorted alphabetically so `gap-testkit::workspace_crates_match_layers_and_workspace_deps` (`ARC-001`) and `tools/check_layers.py` stay green. `gap-testkit` remains in `[exempt_dev]` and is used by `gap-conformance` only under `[dev-dependencies]`.
  3. `crates/gap-conformance/src/ngc_kit/` (`WP-M1-04`) and `crates/gap-testkit/src/chaos/` (`WP-M3-08`) remain untouched.
  4. `tools/spec_trace.py` validates `spec: <ID>` markers in Rust sources strictly against IDs defined in `spec/*.md` (`ARC-001`, `ARC-003`, `ARC-005`, `ARC-007`, `GQL-002`, `GQL-003`, `GQL-062`, `GQL-070`, `INV-02`, `INV-09`, `INV-15`, `NGC-020`, `NGC-026`, `NGC-091`, `SEC-040`, `SEC-041`). References to `VER-010`..`VER-012` and `ADR-*` are placed inside parentheses after the `spec:` list so `spec_trace.py` reports `0 unknown test IDs`.
  5. Seatbelt in this environment allows `127.0.0.1:0` `bind()`/`listen()` (so `PortAllocator` reservation tests pass) while rejecting loopback `connect()` with `Operation not permitted (os error 1)`. Per protocol, in-process `axum` loopback client-server tests live in `crates/gap-conformance/tests/http_loopback.rs` without `#[ignore]` or skip guards so they fail visibly in Seatbelt (recorded under Deviations as `NOT RUN`) and pass cleanly outside the sandbox.
- **Rejected simpler alternative:**
  - *Alternative A (greedy scan for `{"unordered": true, "items": [...]}`):* Matching each expected array item to the first compatible observed item fails when `expect[0]` (`{"a": 1}`) is a proper subset of `observed[0]` (`{"a": 1, "b": 2}`) while `expect[1]` (`{"a": 1, "b": 2}`) can match only `observed[0]`. Rejected in favor of Kuhn's augmenting-paths bipartite matching algorithm (`O(n^3)` worst case, exact 1-to-1 pairing).
  - *Alternative B (second `ManualClock` struct or bind-then-close port picker in `gap-testkit`):* Rejected because duplicating `gap_core::clock::ManualClock` risks clock drift across crates, and closing a temporary `127.0.0.1:0` socket before `axum::serve` re-binds creates a TOCTOU port-collision race under parallel test execution.
- **Risks:**
  1. `serde_json::Number` equality (`Number == Number`) distinguishes `1` (`u64`) from `1.0` (`f64`), whereas casting `u64`/`i64` to `f64` loses precision above $2^{53}$. Mitigated by comparing integer representations directly (`i128`) and converting integral finite `f64` values within `[-2^127, 2^127)` to `i128` before comparison.
  2. `reqwest` is deliberately compiled without a TLS backend (`ADR-002`); an `https://` target URL could surface an opaque builder/connector error if sent directly to `reqwest`. Mitigated by validating the parsed URL scheme up front in `HttpDriver::new` and returning a clear typed `DriverError::HttpsUnsupported` without network access.
  3. Bearer tokens loaded from `--principals <file.json>` could leak via `reqwest` header `Debug` output, tracing spans/events, error messages, or failure details (`INV-15`). Mitigated by storing tokens as `gap_core::secret::SecretString`, marking `Authorization` `HeaderValue::set_sensitive(true)`, redacting `PrincipalsMap` `Debug` output, scrubbing loaded secret tokens from report/error details, and proving non-leakage through `gap_testkit::CanarySink`.
