   - Implement Reciprocal Rank Fusion (`1 / (60 + rank)` normalized by `2 / 61`), canonical document sorting (`RTE-010`), deterministic `index_hash`, `HybridElementIndex` + `ScopedElementSearch` implementing `gap_core::traits::ElementSearch`, and comprehensive `// spec:` tests (`RTE-001`, `RTE-003`, `RTE-004`, `RTE-005`, `RTE-006`, `RTE-010`, `INV-05`).

   - Add deterministic quick-mode microbenchmark over 1,000 elements measuring hybrid BM25 + dense + RRF latency (`cargo bench -p gap-index -- --quick`).
5. **Model manager & BGE embedder (`crates/gap-models/src/lib.rs`):**
   - Implement `ModelManifest::parse` / `load_from_path` parsing TOML `models/manifest.toml` records (`id`, `url`, `sha256`, `size`, `license`, `source_commit`, `training_data_note`), pure safe Rust FIPS 180-4 SHA-256 verification, and `ModelManager` enforcing `offline_mode = true` fail-closed behavior plus size/checksum/existence verification (`SEC-102`).
   - Implement `EmbeddingModel` trait, deterministic offline `BgeSmallEnV15Model` (also implementing `gap_core::traits::Embedder`) emitting L2-normalized 384-d embeddings with `Represent this sentence for searching relevant passages: ` query prefixing, and bounded TTL `QueryEmbeddingCache` (`RTE-002`).
   - Add `// spec:` unit tests for `SEC-102` and `RTE-002`.
