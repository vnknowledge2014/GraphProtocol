# Step Plan — WP-M4-02 (Extractors: OpenAPI, gRPC, GraphQL, SQL)

- **Work Package:** `WP-M4-02`
- **Branch:** `wp/WP-M4-02`
- **Owns:** `crates/gap-ingest/src/extractors/openapi/**`, `crates/gap-ingest/src/extractors/grpc/**`, `crates/gap-ingest/src/extractors/graphql/**`, `crates/gap-ingest/src/extractors/sql/**`, `fuzz/fuzz_targets/fuzz_extract_openapi.rs`, `fuzz/fuzz_targets/fuzz_extract_proto.rs`, `fuzz/fuzz_targets/fuzz_extract_graphql.rs`, `fuzz/fuzz_targets/fuzz_extract_sql.rs`, `tests/fixtures/specs/**`
- **Spec Refs:** `ING-010`, `ING-012`, `ING-020`, `ING-021`

## Steps

1. **OpenAPI 3.0/3.1 + Swagger 2.0 Extractor (`crates/gap-ingest/src/extractors/openapi/mod.rs`)**
   - Parse bounded JSON via `super::mcp::parse_bounded_json`; convert Swagger 2.0 (`swagger == "2.0"`, `definitions`, `basePath`, `host`) into OpenAPI 3 semantics deterministically.
   - Resolve local JSON Pointer `$ref`s (`#/components/...`, `#/definitions/...`) with cycle detection, `max_depth` enforcement, and bounded expansion budget (`ING-012`); reject external `$ref` URLs/files (`ExtractError::Malformed`).
   - Record `servers[].url` as metadata without auto-following (`ING-011`).
   - Map operations with deterministic side-effect derivation (`GET`/`HEAD`/`OPTIONS` -> `Query/None`, `PUT` -> `Mutation/Reversible`, `DELETE` -> `Mutation/Irreversible`, `POST`/`PATCH` -> `Mutation/Unknown`), detect pagination (`Cursor`, `OffsetLimit`), infer `NAME_TYPE` `CandidateJoin`s (`*_id` -> `<Entity>.id`), wrap free text in `UntrustedText` (`ING-020`), and add `extractor_openapi_*` tests.

2. **gRPC `.proto` and Descriptor Extractor (`crates/gap-ingest/src/extractors/grpc/mod.rs`)**
   - Parse both `.proto` (`proto2`/`proto3`) DDL text and descriptor/reflection JSON snapshots within `ExtractLimits`.
   - Extract `message`, nested `message`, `enum`, and `service` `rpc` definitions into `TypeDef`, `KeyDef`, `OperationDef`, and `DocBlob`.
   - Map server-streaming RPCs to `OpKind::Subscription` (`SideEffectLevel::None`), unary `NO_SIDE_EFFECTS`/`IDEMPOTENT` RPCs to `OpKind::Query` (`SideEffectLevel::None`, `idempotent: Some(true)`), other unary RPCs to `OpKind::Mutation` (`SideEffectLevel::Unknown`, `idempotent: None`), reject client-streaming (`ExtractError::Unsupported`), detect `page_token`/`next_page_token` cursor pagination, and add `extractor_grpc_*` tests.

3. **GraphQL SDL and Introspection Extractor (`crates/gap-ingest/src/extractors/graphql/mod.rs`)**
   - Support bounded GraphQL SDL (via `gap_ql::Schema::parse` / `apollo_compiler`) and introspection JSON (`__schema` / `data.__schema`).
   - Map `Query` / `Mutation` / `Subscription` root fields to `OperationDef`, retain native `OBJECT`/`INPUT`/`ENUM`/`INTERFACE`/`SCALAR` `TypeDef`s, extract `@key(fields: ...)` / `id` `KeyDef`s, detect Relay connection pagination (`after`/`first` + `edges`/`pageInfo`), and add `extractor_graphql_*` tests.

4. **SQL DDL and `information_schema` Extractor (`crates/gap-ingest/src/extractors/sql/mod.rs`)**
   - Parse SQL DDL (`CREATE TABLE`, inline & table constraints `PRIMARY KEY`, `UNIQUE`, `FOREIGN KEY ... REFERENCES`, `CREATE UNIQUE INDEX`, comments) and `information_schema` JSON snapshots with zero database access.
   - Emit `TypeDef` per table, `KeyDef` for primary/unique keys, read-only `get_<table>_by_<pk>` and `list_<table>` operations (`SideEffectLevel::None`, `OffsetLimit` pagination), `CandidateJoin` with `JoinEvidence::Fk` for foreign keys (`ING-021`), and add `extractor_sql_*` tests.

5. **Fixtures, Fuzz Targets, Verification & Merge**
   - Populate valid + hostile spec fixtures under `tests/fixtures/specs/` and wire `fuzz/fuzz_targets/fuzz_extract_{openapi,proto,graphql,sql}.rs`.
   - Run `cargo fmt --all -- --check`, `cargo clippy -p gap-ingest --all-targets --offline -- -D warnings`, `cargo nextest run -p gap-ingest --offline`, `tools/check_layers.py`, `tools/wp.py validate`, `tools/check_refs.py`, and `tools/spec_trace.py`.
   - Write `work/handoffs/WP-M4-02.md`, commit, and fast-forward merge `wp/WP-M4-02` into `main`.
