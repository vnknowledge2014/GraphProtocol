# Steps: WP-M2-07 — GAP-Bench v1: direct-MCP vs GAP-facade harness and baseline results

**Work Package:** `WP-M2-07` (`bench/gapbench/**`, `bench/results/gapbench/**`)
**Spec / ADR refs:** `ADR-021`, `CMP-008`, `RTE-034`, `G-F1`, `G-C1`
**Milestone:** M2

---

## Architecture & Layering Checks

- `gapbench` sits at Layer 5 (`tools/layers.toml`) and MUST only depend on Layer `0..=4` crates (never `gap-server`).
- Assemble the full in-process GAP runtime directly using:
  `gap_snapshot::compose` -> `SnapshotBuilder` -> `SnapshotHandle` -> `ConnectorRegistry` (in-memory `BranchClient` connectors) -> `AppState` -> `TransportEngine` -> `McpFacade` (`HttpModule`), plus `gap_store::SqliteContextStore` (WAL `Durability::Off` in `tempfile::TempDir`) and `RouteDiscoveryService`.
- Token accounting follows `GQL-022` (`ceil(utf8_bytes / 4)`) across both uncached and prompt-cached modes (`1.25x` cold prefix write amortized + `0.10x` cached prefix read per subsequent round trip + `1.0x` dynamic prompt/completion tokens).

## Expansion into 2–5 Minute Steps

1. **Dependencies & Verification:**
   - Update `bench/gapbench/Cargo.toml` with alphabetically sorted already-vendored workspace dependencies (`blake3`, `bytes`, `gap-core`, `gap-exec`, `gap-index`, `gap-mcp`, `gap-ngc-sdk`, `gap-plan`, `gap-proto`, `gap-ql`, `gap-route`, `gap-snapshot`, `gap-store`, `gap-transport`, `http`, `reqwest`, `serde`, `serde_json`, `tempfile`, `thiserror`, `tokio`).
   - Run `cargo check -p gapbench --offline` and `python3 tools/check_layers.py` immediately.
2. **Synthetic Multi-Branch & Code-Graph Corpus (`bench/gapbench/src/synth.rs`):**
   - Generate `N`-tool supergraphs (`N in {10, 50, 200, 1000}`) across `B = (N / 10).max(1)` deterministic branches with realistic GraphQL SDL (`Query.<branch>_<op>`, typed fields, cross-branch `Customer` -> `Order` -> `Note` join paths, and direct-MCP `Tool` schemas), composing each `Snapshot` **once per N**.
   - Generate a 20-file synthetic multi-language codebase (~25k+ source tokens, 60 symbols, exact `Calls` / `Imports` / `Defines` edges) backed by both virtual files (Direct-MCP file-scan baseline) and `SqliteContextStore` FTS5 + recursive traversal (GAP context-graph path).
3. **Scripted & Optional OpenAI-Compatible Agents (`bench/gapbench/src/agent.rs`):**
   - Implement `BenchAgent` trait with `ScriptedAgent` driving real `McpFacade::handle` JSON-RPC (`tools/list`, `gap_search`, `gap_query`, and `SqliteContextStore` search/traverse) vs `DirectMcp` (`N`-tool `tools/list` + direct single/N+1/file-scan calls).
   - Add `HttpLlmAgent` (`--llm-endpoint`, `--llm-model`, `GAPBENCH_LLM_API_KEY`) failing closed without hitting network during `--scripted`.
4. **Metrics, Discovery SLOs & Gates (`bench/gapbench/src/metrics.rs`):**
   - Compute prompt tokens before first useful call, uncached & prompt-cached tokens/success, success rate, mean round trips, p50/p95/p99 latency, `__metaGraph` token size (`RTE-034`), `__search` p50/p95 ms + `recall@10` (`>= 0.95`, `<= 40 ms`), `G-F1` (`tools/list <= 1200`), and `G-C1` (`code_graph` tokens `<= 15%` at `>=` accuracy).
   - Write structured `baseline.json` (with git commit, OS/arch, profile, env metadata) and formatted `README.md`.
5. **CLI & Tests (`bench/gapbench/src/main.rs`):**
   - Support `--suite`, `--n`, `--scripted`, `--llm-endpoint`, `--llm-model`, `--out`, `--help`.
   - Add 4 tests tagged `// spec: CMP-008` and `// spec: RTE-034` covering `G-F1` across `N`-sweep, `__metaGraph` + `__search` p95/recall@10, `G-C1` + `cross_branch_join` token advantage, and CLI artifact output.
6. **Baseline Capture, Verification & Handoff:**
   - Run full `--release --suite all --n 10,50,200,1000 --scripted --out bench/results/gapbench` + debug smoke `--n 10,50 --out target/gapbench-smoke`.
   - Verify `cargo fmt --check`, `cargo clippy`, `cargo nextest`, `cargo deny --offline check bans licenses sources`, `check_layers.py`, `wp.py validate`, `check_refs.py`, `spec_trace.py`.
   - Write `work/handoffs/WP-M2-07.md`, update status, commit & ff-merge to `main`.

## Assumptions & Risks

- `QueryResponse` protobuf encoding over `BranchClient` must match what `ExecLayer` decodes (`prost_types::Struct` or JSON payload in `QueryResponse`); verify exact field mapping against `crates/gap-exec` before coding `synth.rs`.
- `N = 1000` operations (100 branches) in `gap_snapshot::compose` should remain fast when built once per `N`; measure release & debug runtimes empirically.
