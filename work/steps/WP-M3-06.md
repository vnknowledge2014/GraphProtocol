# WP-M3-06 steps — `gap-ngc-grpc` and `gap-ngc-graphql` connectors (`CMP-050`, `NGC-020`, `NGC-026`, `spec/09-compat.md` §§5.3–5.4)

Goal: Implement both L4 adapters:
1. `adapters/gap-ngc-grpc`: dynamic gRPC/Protobuf `NativeGraphConnector` driven by compiled `.proto` sources (`protox`), encoded `FileDescriptorSet` bytes, or live gRPC Server Reflection (`grpc.reflection.v1.ServerReflection` / `v1alpha`), mapping unary RPCs to `QUERY` (only when `idempotency_level` is `NO_SIDE_EFFECTS` or `IDEMPOTENT` AND accepted by a T0/T1 admin policy; else `MUTATION` with `SideEffectHint::SIDE_EFFECT_UNSPECIFIED`) and server-streaming RPCs to `SUBSCRIPTION`, enforcing per-call deadlines (`NGC-025`), redacting & injecting configured metadata credentials without bearer token passthrough (`SEC-011`, `INV-15`), batching `foreach` calls with `gap_ngc_sdk::foreach` and reporting honest `Complete.upstream_calls` (`NGC-020`, `NGC-026`).
2. `adapters/gap-ngc-graphql`: outbound GraphQL `NativeGraphConnector` driven by upstream SDL or GraphQL introspection, namespacing upstream types with `<ns>_<Type>`, detecting Relay connections (`edges { node cursor } pageInfo { hasNextPage endCursor }`), rewriting selection sets and variables cleanly to upstream type names, accepting any `2xx` HTTP response (specifically `200`/`294`) and parsing `application/graphql-response+json` (`ADR-023`), enforcing deadlines without bearer passthrough, and batching `foreach` via Apollo Federation `_entities(representations: $reps)` (when supported) or aliased root fields (`_b0: ...`) over `gap_ngc_sdk::foreach` so `N` keys execute in `ceil(N / max_batch_size)` calls (`NGC-020`, `NGC-026`, `INV-18`).

Spec & ADR coverage: `spec/09-compat.md` §§5.3–5.4, `spec/03-ngc.md` (`NGC-010`, `NGC-012`, `NGC-013`, `NGC-015`, `NGC-020`, `NGC-024`, `NGC-025`, `NGC-026`), `spec/02-gap-ql.md` (`GQL-004`), `spec/07-security.md` (`SEC-011`), `spec/01-architecture.md` (`INV-15`, `INV-18`), `ADR-015`, `ADR-023`.

Note on workspace layer boundaries & offline deps:
- Owned paths only: `adapters/gap-ngc-grpc/**`, `adapters/gap-ngc-graphql/**`, `tests/fixtures/grpc/**`, `tests/fixtures/graphql/**`.
- Strictly use already-vendored workspace crates/features (`prost`, `prost-reflect`, `prost-types`, `protox`, `tonic`, `tonic-prost`, `apollo-compiler`, `apollo-parser`, `axum`, `hyper`, `hyper-util`, `http`, `http-body-util`, `reqwest`, `tower`, `tokio`, `tokio-stream`, `tokio-util`, `futures-util`, `blake3`, `bytes`, `serde`, `serde_json`, `thiserror`, `tracing`, `url`, `proptest`). Note `tonic-reflection` is not vendored in `.local/vendor`; live reflection uses dynamic gRPC `grpc.reflection.v1.ServerReflection` / `v1alpha` wire framing built directly over `tonic` + `prost`.

## Steps

### Step 1 — Offline dependency manifests & test fixtures
1. Update `adapters/gap-ngc-grpc/Cargo.toml` and `adapters/gap-ngc-graphql/Cargo.toml` using workspace dependencies with no unvendored features.
2. Add realistic fixtures:
   - `tests/fixtures/grpc/inventory.proto` (unary `NO_SIDE_EFFECTS`, unary `IDEMPOTENT`, unary unspecified/mutating, server-streaming event RPC, nested/repeated messages, maps, enums).
   - `tests/fixtures/graphql/inventory.graphql` (Query, Mutation, Relay `ProductConnection` / `ProductEdge` / `PageInfo`, Apollo `@key` / `_entities` union `_Entity` variant + non-federated query fields).
3. Verify `cargo check -p gap-ngc-grpc -p gap-ngc-graphql --offline` succeeds cleanly.

### Step 2 — `gap-ngc-grpc`: Config, credentials, & schema reflection/descriptor mapping (`spec/09-compat.md` §5.3)
1. `src/config.rs`:
   - `TrustTier` (`T0`, `T1`, `T2`), `AdminSideEffectPolicy` (admin-approved read-only method allow-list / trusting `idempotency_level` only for `T0`/`T1`), `GrpcAuthConfig` (metadata header/bearer/api-key using `gap_core::secret::Secret<String>` and redacted `Debug`), `DescriptorSource` (`FileDescriptorSet(Vec<u8>)`, `ProtoFiles { files, includes }`, `ServerReflection`), `GrpcConfig` (`connector_id`, `endpoint`, `trust_tier`, `limits`, `method_deadlines`, etc.).
2. `src/reflect.rs`:
   - Compile `.proto` via `protox` into `DescriptorPool`, decode raw `FileDescriptorSet`, or fetch transitive `FileDescriptorProto`s over `grpc.reflection.v1.ServerReflection` (with fallback to `grpc.reflection.v1alpha.ServerReflection`) via `GrpcTransport`.
   - Note: `GrpcTransport` trait abstracts unary, server-streaming, and bidi reflection calls over `tonic::transport::Channel` (plus in-memory/tower channels for offline tests).
3. `src/schema.rs`:
   - Inspect `DescriptorPool` services/methods:
     - Client-streaming or bidi-streaming application RPCs are skipped/recorded as unsupported in MVP, while server-streaming RPCs become `OpKind::Subscription`.
     - Unary RPCs inspect protobuf `MethodOptions.idempotency_level` (`NO_SIDE_EFFECTS` / `IDEMPOTENT` / unspecified): ONLY classified as `OpKind::Query` when `idempotency_level` is `NO_SIDE_EFFECTS` or `IDEMPOTENT` **and** `trust_tier` is `T0`/`T1` with admin policy acceptance; otherwise `OpKind::Mutation` with `SideEffectHint::SideEffectUnspecified` (`ADR-015`, `spec/09-compat.md` §5.3).
   - Generate JSON Schema 2020-12 `input_schema`/`output_schema` and valid GAP-QL `schema_sdl` (avoiding GAP built-ins `Query`/`Mutation`/`Subscription`/`__`/`String`/`Int`/`Float`/`Boolean`/`ID`, mapping `int64`/`uint64` safely, nested message/enum definitions, bounded recursion).

### Step 3 — `gap-ngc-grpc`: Dynamic codec, invocation, deadlines, credentials, & `foreach` (`NGC-020`, `NGC-025`, `NGC-026`)
1. `src/codec.rs`:
   - Raw `prost::bytes::Bytes` `Codec` for `tonic::client::Grpc` plus JSON <-> `prost_reflect::DynamicMessage` protobuf wire encode/decode (supporting `Selection` field projection onto returned `prost_types::Struct` rows).
2. `src/connector.rs`:
   - `GrpcConnector<T: GrpcTransport>`: implements `gap_ngc_sdk::connector::Connector` (`describe`, `query`, `mutate`, `subscribe`, `health`).
   - Enforces per-method deadline (`min(CallScope::deadline, method_deadline)`), injects only configured connector metadata credentials (never copying caller `authorization` / `CallScope.metadata` bearer tokens — `SEC-011`), propagates `traceparent`/`x-request-id`.
   - `query`: supports both single execution (`QueryRequest.foreach` empty) and `foreach` via `gap_ngc_sdk::foreach::foreach` with bounded `max_in_flight`/`max_batch_size`, emitting honest `Complete.upstream_calls` and honoring cancellation/deadline (`NGC-020`, `NGC-025`, `NGC-026`).
   - `mutate`: handles unary `MUTATION` RPCs, supports `dry_run` report when enabled, refuses mutation on unknown ops or unapproved read-only constraints.
   - `subscribe`: executes server-streaming RPCs into `BoxStream<Event>` honoring `CallScope.cancel` and deadline.
3. Unit + integration tests in `adapters/gap-ngc-grpc/tests/grpc_connector.rs` spinning up an in-process `tonic` gRPC server (including `ServerReflection` v1 + unary/streaming RPCs) over `127.0.0.1:0` and verifying all `spec_refs` + metadata redaction + bearer non-passthrough.

### Step 4 — `gap-ngc-graphql`: Config, SDL/Introspection normalization, & selection rewriting (`spec/09-compat.md` §5.4)
1. `src/config.rs`:
   - `UpstreamSchemaSource` (`Sdl(String)` or live `__schema` introspection JSON), `GraphqlAuthConfig` (`Secret<String>` bearer/header, redacted `Debug`), `GraphqlConfig` (`connector_id`, `branch_namespace`, `endpoint`, `limits`, `prefer_federation_entities`, `read_only`, `max_response_bytes`).
2. `src/schema.rs`:
   - Parse upstream SDL (or convert introspection JSON -> SDL) using `apollo-compiler` / `apollo-parser`.
   - Namespace every upstream non-builtin object/interface/union/enum/input/scalar `<Type>` as `<ns>_<Type>` (handling `__` / GAP built-in collisions per `GQL-004`).
   - Detect Relay connections cleanly: object type `<T>Connection` with `edges: [<T>Edge]` (`node`, `cursor`) and `pageInfo: PageInfo` (`hasNextPage`, `endCursor`), marking matching operations `PaginationKind::Cursor`.
   - Detect Apollo Federation support (`_entities(representations: [_Any!]!): [_Entity]!` or explicit federation flag) and generate `OperationDescriptor`s (queries -> `OpKind::Query`, mutations -> `OpKind::Mutation` with `SideEffectHint::SideEffectUnspecified` unless admin policy explicitly sets).
3. `src/rewrite.rs`:
   - Parse incoming operation / selection (`Selection` AST from `QueryRequest` / `MutateRequest`) and build an upstream GraphQL document:
     - Rewrite namespaced branch type references `<ns>_<Type>` -> upstream `<Type>` (including inline fragments `... on <ns>_<Type>`).
     - Translate `arguments`, `Page` (`first`/`after`), `OrderBy`, and `Selection` tree recursively into sanitized GraphQL selection sets + `$variables`.
     - Build batched documents for `foreach`:
       - Mode A (Federation `_entities`): single query calling `_entities(representations: $reps)` for up to `max_batch_size` representations (`{ "__typename": "<Type>", ...keys }`) when entity batching applies.
       - Mode B (Aliased root fields): single GraphQL query containing `_b0: <field>(...), _b1: <field>(...), ...` with indexed variables `$v0_...`, `$v1_...` for up to `max_batch_size` distinct variable sets per HTTP call (`ceil(N / max_batch_size)` calls!).

### Step 5 — `gap-ngc-graphql`: Transport (`ADR-023`), connector, & tests (`NGC-020`, `NGC-026`, `ADR-023`)
1. `src/transport.rs`:
   - `GraphqlTransport` trait + `ReqwestGraphqlTransport` (`POST` JSON `{query, variables, operationName}`, `Accept: application/graphql-response+json, application/json;q=0.9`, never forwarding caller bearer token, configured secret header only, hard response byte cap, deadline timeout).
   - Parse HTTP status & media type per `ADR-023`: accept any `2xx` status (including `200 OK` and `294` partial success) and parse `application/graphql-response+json` bodies regardless of status (mapping GraphQL request/execution errors without leaking secrets into `NgcErrorInfo`).
2. `src/connector.rs`:
   - `GraphqlConnector<T: GraphqlTransport>`: implements `Connector` (`describe`, `query`, `mutate`, `health`).
   - Uses `gap_ngc_sdk::foreach::foreach` so `N` keys execute in `ceil(N / max_batch_size)` HTTP calls and reports exact `Complete.upstream_calls`, unwrapping Relay `edges[].node` or preserving connection fields per selection/pagination, and supporting `dry_run` checks on mutations.
3. Unit + integration tests in `adapters/gap-ngc-graphql/tests/graphql_connector.rs` spinning up an in-process `axum` mock GraphQL endpoint (`127.0.0.1:0`) covering namespacing, Relay detection, aliased batching `ceil(N / max_batch_size)`, Apollo `_entities` batching, HTTP `200`/`294` + `application/graphql-response+json` `400`/`422`, deadlines, and credential redaction.
