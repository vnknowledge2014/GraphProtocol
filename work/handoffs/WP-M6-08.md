## What changed

1. **IP CIDR classification & tunnel unwrapping (`crates/gap-sec/src/egress/ip.rs`):**
   - Implemented `CidrBlock` (IPv4 and IPv6 prefix matching including IPv4-mapped IPv6 addresses) and `classify_blocked_ip`.
   - Denies unspecified, loopback, RFC 1918 private, CGNAT, link-local, ULA (`fc00::/7`), multicast, documentation/reserved, and cloud metadata endpoints (`169.254.169.254`, `169.254.170.2`, `100.100.100.200`, `fd00:ec2::254`), while recursively unwrapping IPv4-mapped (`::ffff:0:0/96`), IPv4-compatible, NAT64 (`64:ff9b::/96`, `64:ff9b:1::/48`), 6to4 (`2002::/16`), and Teredo (`2001:0000::/32`) addresses (`SEC-075`).
2. **Hardened URL parser (`crates/gap-sec/src/egress/url_parse.rs`):**
   - Enforces `https` (plus `http` only when explicitly permitted for local dev hosts), denies URL userinfo, denies IPv6 zone IDs (`%`, `%25`), denies trailing-dot `localhost.` / metadata hosts, denies decimal/octal/hex/shorthand numeric IP encodings, and resolves relative HTTP `Location` redirects (`SEC-075`, `SEC-076`).
3. **DNS-pinning `EgressGuard` & connector adapters (`crates/gap-sec/src/egress/guard.rs`, `mod.rs`):**
   - Added `DnsResolver` abstraction, `EgressPolicy` with per-branch `egress.allow[]` host/CIDR overrides and `allow_insecure_http_hosts`, `PinnedEndpoint` (single DNS resolution + `connect_tcp` directly to pinned socket addresses + TLS SNI/Host preservation), `follow_redirects` (`<= 3` hops, no `https` -> `http` downgrade, full re-check per hop), `EgressHttpAdapter` (for OpenAPI/GraphQL/MCP/`SourceFetcher`/`HttpSidecar`), `EgressGrpcAdapter`, and `EgressGuard::self_test()` (`SEC-072`).
4. **Tests (`crates/gap-sec/src/egress/tests.rs`, `tests/security/ssrf/ssrf_egress.rs`, `crates/gap-server/tests/ssrf_egress.rs`):**
   - Covered the full SSRF vector table, redirect-to-metadata / downgrade / loop caps, branch allow-list overrides, live TCP dial pinning, DNS rebinding simulation (public first lookup -> RFC 1918 / metadata / loopback on re-lookup), `SourceFetcher` wrapper enforcement, and `gap doctor` self-test (`SEC-076`, `TM-06`).
