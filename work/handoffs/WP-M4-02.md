## Summary

- Implemented deterministic `OpenApiExtractor` (`crates/gap-ingest/src/extractors/openapi/mod.rs`):
  - Parses OpenAPI 3.0/3.1 and Swagger 2.0 JSON via `parse_bounded_json` within `ExtractLimits { max_bytes, max_depth, max_items, timeout }` (`ING-010`, `ING-012`).
  - Resolves local `$ref` pointers with explicit cycle detection and `limits.max_depth` enforcement, rejecting external `$ref`s (`http://`, `file://`, relative paths) with `ExtractError::Malformed` (`ING-011`).
  - Records `servers[]` / `host` URLs in `DocBlob` metadata without ever fetching or following them; maps HTTP verbs to `SideEffectLevel` deterministically (`ADR-015`); wraps descriptions/docs in `UntrustedText` (`ING-020`); detects cursor and offset/limit pagination and emits `JoinEvidence::NameType` candidate joins (`ING-021`).
- Implemented deterministic `GrpcExtractor` (`crates/gap-ingest/src/extractors/grpc/mod.rs`):
  - Parses proto2/proto3 `.proto` definitions and gRPC reflection / `FileDescriptorSet` JSON within `ExtractLimits`.
  - Handles enums, nested messages, `oneof`, `map<K,V>` (`JSON` scalar), unary `NO_SIDE_EFFECTS`/`IDEMPOTENT` RPCs -> `OpKind::Query` / `SideEffectLevel::None`, unspecified unary -> `OpKind::Mutation` / `SideEffectLevel::Unknown`, server-streaming -> `OpKind::Subscription`, and client/bidi-streaming -> `ExtractError::Unsupported`.
  - Detects cursor pagination conventions and emits `JoinEvidence::NameType` candidate joins.
- Implemented deterministic `GraphqlExtractor` (`crates/gap-ingest/src/extractors/graphql/mod.rs`):
  - Parses GraphQL SDL and `__schema` introspection JSON within `ExtractLimits`.
  - Maps root `Query`/`Mutation`/`Subscription` fields to operations, preserves `@key` directives as `KeyDef`, detects Relay `*Connection` / offset-limit pagination, and emits `JoinEvidence::NameType` candidate joins.
- Implemented deterministic `SqlExtractor` (`crates/gap-ingest/src/extractors/sql/mod.rs`):
  - Parses SQL DDL and `information_schema` JSON snapshots with zero database/network access (`ING-011`).
  - Extracts tables -> `TypeDef`, PKs/unique constraints/unique indexes -> `KeyDef`, FKs -> `CandidateJoin` with `JoinEvidence::Fk`, and read-only `get_<table>_by_<pk>` / `list_<table>` queries with `OffsetLimit` pagination.
- Wired bounded fuzz targets in `fuzz/fuzz_targets/fuzz_extract_{openapi,proto,graphql,sql}.rs` and added sample/hostile fixtures under `tests/fixtures/specs/`.
