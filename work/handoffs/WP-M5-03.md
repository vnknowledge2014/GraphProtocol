## Summary of Changes
1. **`crates/gap-route/src/s1_adapter/semaphore.rs`**: Implemented pure-`std`, lock-free across `.await`, cancel-safe FIFO `BoundedSemaphore`, `SemaphorePermit`, and `AcquireFuture` enforcing `max_concurrency` active permits and bounded waiting depth (`<= 2 * max_concurrency` by default, `RTE-045`), rejecting queue overflow cleanly with `ErrorCode::DiscoveryDegraded`.
2. **`crates/gap-route/src/s1_adapter/mod.rs`**:
   - Added `DecisionBackend::score_choice_with_timeout` and `Arc`/`Box` blanket implementations for both `RoutingModel` and `DecisionBackend`.
   - Upgraded `format_s1_state_jcs` and `format_s1_options` / `format_s1_options_indexed` to sort non-sink options by descending retrieval prior (`key` tie-break), canonically re-key `g0`, `g1`, ..., cap option text to `max(8, floor(0.8 * head_max_len / n_options))` tokens, enforce fixed `SINK_OPTION_TEXT`, and map backend logits back to caller option order (`RTE-042`).
   - Added `S1AdapterConfig` defaults (`max_concurrency = (cores / 2).max(1)`, `max_queue_depth = 2 * max_concurrency`, `cache_ttl_secs = 600`, `failure_rate_threshold = 0.20`, `circuit_cooldown_secs = 60`), `ctx.timeout_ms` deadline checks (`RTE-044`), expired TTL cache pruning (`RTE-046`), and rolling failure circuit cooldown falling back to `BaselineRouter`.
3. **`crates/gap-route/src/s1_adapter/tests.rs`**: Added 5 unit tests verifying `RTE-042` canonical formatting & realignment, `ADR-006` replica-addition invariance with fixture logits, `RTE-046` TTL decision cache hits/expiration, `RTE-045` bounded semaphore queuing & overflow shedding, and `RTE-044` / `INV-17` timeout + rolling-failure circuit cooldown fallback.
4. **`crates/gap-server/src/wiring_s1.rs`**: Implemented `S1BackendMode::{Disabled, CalibratedInMemory, Safetensors}`, `S1WiringConfig`, `TokioTimeoutBackend` (preemptive `tokio::time::timeout`), `WiredS1Discovery`, `wire_s1_discovery`, and `wire_s1_with_backend` with graceful startup/runtime degradation (`GAP_DISCOVERY_DEGRADED` -> `BaselineRouter`), plus 3 integration tests (`inv_17_disabled_and_missing_weights_fall_back_cleanly_and_gateway_executes_queries`, `inv_17_s1_timeout_and_down_backend_degrade_to_baseline_with_warning`, `s1_adapter_wired_laya_candle_safetensors_ranks_groups_end_to_end`).
