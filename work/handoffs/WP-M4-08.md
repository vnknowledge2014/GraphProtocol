## Summary of Changes
1. **`crates/gap-snapshot/src/publisher/mod.rs`:**
   - Implemented `PublisherActor` serializing all snapshot writes via `Mutex<PublisherInner>`, enforcing monotonic generations (`INV-16`), `SNAPSHOT_FORMAT_VERSION` validation (`RUN-004`), and blocking re-promotion of `bad_hashes` unless `PublishOptions::force` is set (`ADR-009` §5).
   - Added `prewarm_snapshot` re-planning up to `prewarm_top_n` (default `100`) hot queries with a `0.95` pass-rate gate unless an audited `BreakingChangeAck` is supplied (`RUN-004`).
   - Added 5-generation structural-sharing ring (`DEFAULT_RING_CAPACITY = 5`) sharing exact `Arc<Snapshot>` pointers across `SnapshotHandle`, `inner.ring`, and `ReclaimerHandle` so retired allocations drop off-thread on dedicated thread `gap-snapshot-reclaimer` only after all reader pins release (`RUN-006`, `ADR-009` §2).
   - Added `CoalescingPublishQueue` (`DEFAULT_COALESCE_WINDOW_MS = 250`, `RUN-006`) and `ShadowRegistry` requiring `admin:schema` scope and `shadow:<id>` header isolation (`ING-050`).
   - Added `rollback_to_generation` and `quarantine_branch_and_publish` for clean single-step or branch-isolated recovery (`RUN-007`).

2. **`crates/gap-snapshot/src/rollback/mod.rs`:**
   - Implemented `RollbackWatcher` with configurable `WatchConfig` (defaults: `60 s` window, `200` min samples, `2.0x` multiplier / `+0.02` delta baseline comparison, `3` auto-quarantines per `24 h` before `HardQuarantined`).
   - Implemented attribution logic isolating changed branches and new join edges while ignoring `WatchSignal::UnrelatedInfraFailure` (`ADR-009` §5) and falling back to `RollbackDecision::FullRollback` on unattributed planning/validation regressions (`RUN-007`).

3. **`tests/swap_stress/swap_stress.rs` & `crates/gap-snapshot/tests/swap_stress.rs`:**
   - `run_008_swap_stress_1000_concurrent_tasks_100_swaps`: 1,000 Tokio tasks concurrently pinning snapshots across 100 swaps with zero torn/non-monotonic reads and full off-thread reclaimer drain (`enqueued = 96, reclaimed = 96, pending = 0`).
   - `run_008_busy_readers_swap_p99_and_structural_sharing_rss`: 256 busy reader OS threads during 100 delta swaps (`swap_us p99 <= 250 us`) and 5-generation structural sharing check (`104/100` unique `Arc<BranchDescriptor>`s, `+4% <= +15%`).
   - `run_007_state_machine_interleaving_publisher_reclaimer_rollback`: deterministic schedule exploration over publish, pin/release, infra noise, branch quarantine rollback, bad-gen re-promotion guards, and reclaimer flushing.
