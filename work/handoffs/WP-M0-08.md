  3. [Layer L0 boundary — NgcError] `gap-core` is layer `L0` (`tools/layers.toml`) and may not depend on `gap-proto` (`L1`). `crates/gap-core/src/error.rs` therefore defines plain `NgcErrorCode` and `NgcErrorInfo` mirroring `NgcError` in `proto/gap/ngc/v1/ngc.proto` with bidirectional `From`/`TryFrom` conversions to and from `GapError` (`NGC-060`, `NGC-031`). Conversion to and from the prost-generated `gap_proto` `NgcError` type belongs to `gap-proto` / `gap-ngc-sdk` (`WP-M1-03`).
  4. [UNSPECIFIED NGC error code fallback mappings] Outside the explicit `NGC-060` (`UNAVAILABLE`/`UPSTREAM_ERROR -> GAP_BRANCH_ERROR`, `DEADLINE_EXCEEDED -> GAP_BRANCH_TIMEOUT`, `PERMISSION_DENIED -> GAP_FORBIDDEN`, `RESOURCE_EXHAUSTED -> GAP_RATE_LIMITED`) and `NGC-031` (`UNIMPLEMENTED -> GAP_DRY_RUN_UNSUPPORTED` on dry-run) mappings, `From<NgcErrorInfo> for GapError` maps `UNAUTHENTICATED -> GAP_UNAUTHENTICATED`, `INVALID_ARGUMENT -> GAP_VALIDATION_ERROR`, `UNIMPLEMENTED -> GAP_UNSUPPORTED_FEATURE`, `CANCELLED -> GAP_CANCELLED`, `CONFLICT -> GAP_IDEMPOTENCY_CONFLICT`, and `NOT_FOUND | FAILED_PRECONDITION | INTERNAL | ERROR_CODE_UNSPECIFIED -> GAP_BRANCH_ERROR`.
  5. [UNSPECIFIED ID validation rules] Where `spec/00-conventions.md` §7 is silent, the narrowest rules consistent with spec examples and `ADR-018` were chosen:
     - `TenantId`: shares the grouped slug rule `[a-z][a-z0-9_-]{1,62}` (`2..=63` ASCII bytes) with `TenantId::default_tenant() == "default"` (`ADR-018`).
     - `OperationId`: `<branch>.<name>` requires `<branch>` to validate as `BranchId`, `<name>` to match `[A-Za-z_][A-Za-z0-9_]{0,127}` (`1..=128` ASCII bytes), and rejects `__`-prefixed names (`GQL-004`).
     - `GroupId`: lowercase-only 32-char hex `[0-9a-f]{32}` (`blake3-128`).
     - `IdempotencyKey`: `1..=128` ASCII `[A-Za-z0-9._:-]` characters (`[A-Za-z0-9._:-]{1,128}`).
  6. [Snapshot persistent map container] `Snapshot.branches` and `Snapshot.groups` use `Arc<BTreeMap<BranchUid, Arc<BranchDescriptor>>>` and `Arc<BTreeMap<GroupId, Arc<CapabilityGroup>>>` instead of `im::OrdMap` (`spec/01-architecture.md` §4 sketch) because `im` is outside `WP-M0-08`'s allowed third-party dependency list; unchanged `Arc<BranchDescriptor>` and `Arc<CapabilityGroup>` entries are still shared across generations (`ARC-005`), and `WP-M1-05` / `WP-M4-08` own `crates/gap-core/src/snapshot/**`.
