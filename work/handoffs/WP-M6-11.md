## Summary of Changes

1. **Append-Only BLAKE3 Hash-Chained Audit Log (`crates/gap-store/src/audit/`):**
   - `canonical.rs`: Implements deterministic sorted-key canonical JSON encoding and `blake3(prev_hash || canonical_json(record_without_hash))` computation (`SEC-090`) starting from `[0u8; 32]` genesis `prev_hash`, `AuditEventClass` (`Privileged` vs `Standard`), entry validation, and `verify_ordered_records` continuity/digest verifier.
   - `memory.rs` & `sqlite.rs`: Provide thread-safe `InMemoryAuditLog` and persistent SQLite WAL `SqliteAuditLog` isolating per-tenant chains (`tenant:<id>`, `INV-09`) from the gateway `system` chain, flushing privileged events (`mutate*`, `approval*`, `admin*`, `policy*`, `ingest.activate*`) synchronously while batching standard events within `<= 100 ms`, and supporting `verify_startup` (`System`, last `10_000` records) plus `verify_nightly_all` (`SEC-092`).
   - `tests.rs`: Verifies `INV-14`, `SEC-090`, `SEC-092`, `INV-09`, and `TM-17` tamper scenarios (record modification, `prev_hash` corruption, deletion, and physical reordering) pinpointing the first inconsistent sequence number in both memory and SQLite WAL stores.

2. **Ed25519 Signed Anchoring & W3C `PROV-O` Export (`crates/gap-sec/src/audit/`):**
   - `anchor.rs`: Implements `AuditAnchor` (Ed25519 signature over domain-separated canonical JSON head state), `AnchorScheduler` (`600 s` / `10 min` cadence), `FileAnchorSink` (`0600` NDJSON file sink), `SyslogAnchorSink` (RFC 5424 structured syslog), `S3CompatibleAnchorSink` (versioned immutable object keys + `sha256` digest), and `verify_chain_against_anchor` detecting truncation and hash rewrites (`SEC-091`, `TM-17`).
   - `provo.rs`: Implements `export_prov_jsonld` mapping audit records to W3C `PROV-O` JSON-LD (`prov:Activity`, `prov:Agent` with `prov:actedOnBehalfOf` delegation chains, and `prov:Entity`, `SEC-093`).
