# Handoff: WP-M6-05 — Cedar Authorization (`gap-sec/src/authz` & `policies/`)

## Summary
Implemented the pure-Rust Cedar schema/policy subsystem and deterministic authorization engine for GAP (`SEC-020`, `SEC-021`, `SEC-022`, `SEC-023`, `SEC-024`, `SEC-012`, `INV-04`, `INV-05`, `RTE-010`; threat IDs `TM-21`, `TM-22`), including default policy assets in `policies/`, atomic hot-reload with BLAKE3 `policy_version`, strict delegation intersection, per-field join authorization (`NULL_WITH_ERROR`, `@pii` masking, generic error messages without rule ID leakage), discovery visibility bitsets, and `SEC-024` decision logging.

## Changes
- `policies/schema.cedarschema`, `policies/default.cedar`, `policies/auto-approve.cedar`: GAP Cedar entity schema (`Tenant`, `Group`, `Principal`, `Branch`, `Element`, `Operation`, `Task`, `Approval`, `Proposal`), 13 actions (`Discover`, `Execute`, `Traverse`, `Mutate`, `SubmitTask`, `DecideApproval`, `CancelTask`, `ProposeSource`, `DecideProposal`, `AdminSchema`, `AdminIngest`, `AdminImpersonate`, `AdminPolicy`), default-deny posture, cross-tenant `forbid`, `T2` mutation `forbid`, unapproved `IRREVERSIBLE`/`UNKNOWN` `forbid`, Rule-of-Two `riskScore >= 100` `forbid`, and optional reversible `T0` auto-approve policy.
- `crates/gap-sec/src/authz/schema.rs` & `parser.rs`: pure-Rust Cedar schema parser, tokenizer, recursive-descent policy parser, and schema/type validator rejecting malformed policies or unknown entity/action/attribute references.
- `crates/gap-sec/src/authz/engine.rs`: `CompiledPolicySet` (BLAKE3 `policy_version_hex` & `policy_version_u64`), `evaluate_single`, `evaluate_with_delegators`, `evaluate_principal` (delegation intersection), and `PolicyStore` atomic `pin()`/`reload()` retaining the active policy set on validation failure.
- `crates/gap-sec/src/authz/layer.rs` & `mod.rs`: `authorize_plan_surface` evaluating every root and joined RHS field (`TM-21`), `visibility_bitset` for discovery (`RTE-010`, `INV-05`), `@pii` masking without `pii:read`, generic `access denied` client errors (`SEC-023`), and `should_log_decision` / `InMemoryDecisionLog` (`100%` denies, `100%` `Mutate`/`Admin*`/`Decide*` allows, `1%` deterministic sampled read allows).
- `crates/gap-sec/src/authz/tests.rs`: 6 unit tests covering `INV-04`, `INV-05`, `SEC-012`, `SEC-020`..`SEC-024`, `RTE-010`, `TM-21`, and `TM-22`.
