Deviations & ADR addenda:
  1. [NOT RUN gate — cargo-nextest] Acceptance command 1 (`cargo nextest run -p gap-conformance -p gap-testkit`): `cargo-nextest` is not installed in the sandbox and must not be installed under the offline vendored build protocol. Ran `cargo test -p gap-conformance -p gap-testkit --locked --offline` instead and kept `WP-M0-09` in `doing` state in `work/status.toml`.
  2. [NOT RUN in Seatbelt — loopback TCP connect()] In `crates/gap-conformance/tests/http_loopback.rs`, `PortAllocator::reserve()` + `axum::serve` succeed on `127.0.0.1:0`, but outbound loopback `connect()` is blocked by macOS Seatbelt with exact OS error:
       `error sending request for url (http://127.0.0.1:<port>/...): client error (Connect): tcp connect error: Operation not permitted (os error 1)`
     Per `WP-M0-09` protocol, neither `http_driver_posts_to_exact_axum_loopback_url_without_appending_path` nor `cli_target_mode_runs_end_to_end_against_axum_and_writes_report` is skipped or marked `#[ignore]`; both remain active so the reviewer can run them outside Seatbelt.
  3. [UNSPECIFIED numeric equality above 2^53] `spec/02-gap-ql.md` §11 states "numbers compare by value". Because converting 64-bit JSON integers to `f64` loses precision above 2^53 (e.g., `9007199254740992` vs `9007199254740993`), `matcher::numbers_equal` compares `i64`/`u64` values in exact `i128` space and converts finite integral `f64` values (`fract() == 0.0` within `[-2^127, 2^127)`) to `i128` before comparison, falling back to `f64` comparison for non-integral floats.
  4. [UNSPECIFIED duplicate HTTP response header folding] `spec/02-gap-ql.md` §11 defines `ObservedResponse.headers` as a map from lower-cased header name to string. When an HTTP response carries multiple values for the same header name, `ObservedResponse::from_parts` concatenates them in wire order separated by `", "` per RFC 9110 §5.3.
  5. [UNSPECIFIED PortAllocator async handoff without tokio/net] `WP-M0-09` restricts `gap-testkit` `tokio` features to `(macros, rt, sync, test-util, time)` (without `net`). `ReservedListener` therefore retains ownership of the bound `std::net::TcpListener` and exposes `into_std(self)` plus `into_nonblocking_std(self) -> Result<std::net::TcpListener, PortAllocError>`, which callers in Tokio/Axum crates pass directly to `tokio::net::TcpListener::from_std` without ever closing and re-binding the port.
  6. [UNSPECIFIED JSON report structure details] `ConformanceReport` serializes `runner { name, version }`, `target`, optional `generated_at` (`skip_serializing_if = "Option::is_none"`, populated only when a `gap_core::clock::Clock` is injected per `INV-02`), `fixtures[]`, `summary { total, passed, failed, errors, spec_ids_total, spec_ids_covered }`, and `coverage: BTreeMap<String, SpecCoverageEntry>` where `SpecCoverageEntry { covered, passed, fixtures }` sets `covered = (passed >= 1)` per `spec/02-gap-ql.md` §11.
  7.
