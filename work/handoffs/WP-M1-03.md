Deviations & ADR addenda:
  1. [NOT RUN gate] Acceptance command 1 (`cargo nextest run -p gap-ngc-sdk`): `cargo-nextest` is not installed in this offline sandbox and must not be installed. Ran `cargo test -p gap-ngc-sdk --locked --offline` across 3 consecutive runs (24/24 passing each run) and left `WP-M1-03` status as `doing` in `work/status.toml`.
  2. [Orphan-rule conversion shape in `error.rs`] Because `gap_core::error::NgcErrorInfo`, `gap_proto::ngc::v1::NgcError`, and `tonic::Status` are all defined outside `gap-ngc-sdk`, Rust's coherence rules forbid implementing foreign `From`/`TryFrom` traits directly between them. `crates/gap-ngc-sdk/src/error.rs` exposes both explicit functions (`ngc_error_to_proto`, `ngc_error_from_proto`, `ngc_error_to_status`, `status_to_ngc_error`) and the `NgcErrorExt` extension trait on `NgcErrorInfo`.
  3. [`prost-reflect` 0.16.5 unknown-field vs unknown-enum JSON semantics] In `prost-reflect` 0.16.5, `DeserializeOptions::new().deny_unknown_fields(false)` also treats unknown enum string names as `None` (default `0`) rather than rejecting them. To satisfy both `NGC-002` requirements simultaneously (ignore unknown message fields like the binary decoder while rejecting unknown enum names and wrong JSON types with `INVALID_ARGUMENT`), `crates/gap-ngc-sdk/src/json.rs` recursively prunes unknown object keys guided by `MessageDescriptor` (leaving `google.protobuf.*` Well-Known Types untouched so arbitrary `Struct` keys survive) and then deserializes with `deny_unknown_fields(true)`.
  4. [Slow-loris bounds on HTTP body and partial stdio lines (`NGC-093` (f), `NGC-094`, `NGC-095`)] `http.rs` bounds streaming request body reads by `health_timeout` (for `/gap/ngc/v1/Health`) or `default_timeout` (returning `504 Gateway Timeout` with `DEADLINE_EXCEEDED` on stalled bodies) and rejects bodies exceeding `max_request_bytes` immediately with `413 Payload Too Large` (`INVALID_ARGUMENT`). `stdio.rs` keeps idle sessions unbounded (`buf.is_empty()`), starts a `default_timeout` timer as soon as the first byte of an unterminated line arrives (returning fatal `-32600` `DEADLINE_EXCEEDED` and closing the session on mid-line stalls), and rejects lines exceeding `max_request_bytes` before buffering excess with fatal `-32600` `INVALID_ARGUMENT`.
  5. [Sandbox environment] Plain `git` (`GIT_CONFIG_GLOBAL=/dev/null GIT_CONFIG_SYSTEM=/dev/null`) and temporary `CARGO_HOME=.git/tmp-cargo-home` were used during offline builds/tests; `.git/tmp-cargo-home` was deleted prior to committing this handoff (`test ! -e .git/tmp-cargo-home`), and `omni index` was not run in this offline sandbox.
