## Key Design Decisions

1. **Zero new dependencies in `gap-ingest`:** `drift/classify.rs` implements structural SDL parsing and canonical `prost_types::Struct` normalization in pure Rust alongside `gap_ql::validate_branch_sdl_reserved_names` and `gap_ql::with_gap_builtins`, keeping workspace crate layering intact without editing `Cargo.toml`.
2. **Pinned execution safety (`INV-08`, `SEC-082`):** Unreviewed drift (including description-only modifications) never mutates the served synopsis (`served_operation` / `served_synopsis` keep returning the pinned version), preventing runtime description poisoning until an operator explicitly approves via `approve_repin`. Structural drift blocks execution with `GAP_BRANCH_DRIFT`.
3. **Incremental composition & 24h removal grace:** `IncrementalComposer` indexes unchanged branch descriptors by normalized hash/signature while delegating final schema/group composition through `compose()` and `assign_capability_groups()`. Removed operations remain resolvable in `BranchRemovalTracker` for `24h` so callers receive `GAP_BRANCH_UNAVAILABLE` and a sibling `suggestion.alternative` when one exists.
