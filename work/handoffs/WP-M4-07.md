## Summary

- Implemented the 13-state ingestion proposal lifecycle (`PROPOSED`..`STABLE`, `REJECTED`, `FAILED`, `ROLLED_BACK`) persisted in `ContextStore` and audited into `AuditLog` (`crates/gap-ingest/src/proposals/`):
  - **`types.rs`:** `ProposalStatus` (`can_transition_to`, `is_open`), `ApprovalDecision`, `AdminCaller`, `ApprovalPolicyConfig` (fail-closed `auto_activate_t0 = false` default, configurable two-person flags for `T2` / cross-trust / mutating sources, `14d` approval TTL), `ProposalReport`, `Proposal`, `ProposalConnection`, and `ProposalError` (`to_gap_error` delegating store errors to `StoreError::into_gap_error`).
  - **`audit_adapter.rs`:** Persistent `ContextStoreAuditLog` (`AuditLog` implementation writing hash-chained `AuditRecord` / `AuditChainHead` nodes into tenant-isolated `ContextStore`) and bounded RFC 8259 JSON parser `parse_cisg_json`.
  - **`service.rs` (`ING-001`..`ING-003`, `ING-035`, `ING-050`, `ING-051`, `INV-09`, `INV-14`, `RUN-025`, `SEC-090`):** `ProposalService` persisting proposal nodes under `proposal_index:root` -> `HAS_PROPOSAL` -> `proposal:<id>`; `canonicalize_location` for `(tenant, canonical_location, kind)` open-proposal idempotency; `T2` extraction gate requiring `admin:ingest`; `T0` auto-activation gate blocked when unsigned, breaking, or `enrichment=degraded`; two-person distinct principal enforcement and `breaking_change_ack`; 14-day approval TTL expiry (`AWAITING_APPROVAL -> REJECTED`); `authorize_shadow_header` requiring `admin:schema` (`X-Gap-Snapshot: shadow:<id>`); signed cursor pagination (`CursorKey`); and `gap_ingest_transitions_total` transition counters.
  - **`discovery.rs` (`RTE-100`..`RTE-103`, `GQL-071`):** Deterministic `redact_query` stripping secrets/PII, `UnmappedEventIntake` with opt-in `privacy_store_queries` (`<= 7d` TTL), 10-minute `(tenant, query_hash)` singleflight coalescing, `10/min/tenant` rate limit (`dropped_total` metric), immediate `insufficient_evidence_error` (`GAP_INSUFFICIENT_EVIDENCE` + `NextStep::ProposeSource`), and allow-listed `DiscoveryWorker` emitting strictly `PROPOSED` proposals without extraction or activation.
  - **`graphql.rs`:** Canonical `CisgValue` handlers for `proposeSource`, `decideProposal` (`DecideProposalInput`), and `proposals` (`ADMIN_INGEST_SCOPE` / `ADMIN_SCHEMA_SCOPE` gated).
- Implemented local operator CLI handlers (`list`, `show`, `approve`, `deny`) in `crates/gap-cli/src/proposals/mod.rs` (`ProposalsCli`, `ProposalsCommand`, `run_proposals_cli`), keeping top-level `crates/gap-cli/src/cli.rs` and `tests/cli.rs` untouched until `WP-M7-01` wiring.
