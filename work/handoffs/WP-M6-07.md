# Handoff: WP-M6-07 — Vault, secret types, redaction layer, canary-secret tests

- **Branch:** `wp/WP-M6-07`
- **Status:** `done`
- **Spec refs:** `SEC-040`, `SEC-041`, `SEC-042`, `INV-15`, `TM-18`

## What changed

1. **Zeroizing secret containers (`crates/gap-sec/src/vault/secret.rs`):**
   - Added `SecretBytes` and `SecretString` that wipe backing memory on `Drop` using `std::hint::black_box` plus `std::sync::atomic::compiler_fence(Ordering::SeqCst)` without requiring `unsafe` (`#![forbid(unsafe_code)]`).
   - `Debug` and `Display` always format as `"***"`; added constant-time equality (`ct_equals`) and explicit `expose_secret` accessors (`INV-15`, `SEC-040`).
2. **Vault providers & hot rotation (`crates/gap-sec/src/vault/provider.rs`):**
   - Defined `SecretKey`, `VaultError` (with automatic error message redaction), and object-safe `Vault` trait.
   - Implemented `EnvVault`, `FileVault` (rejects files looser than Unix mode `0600` on Unix hosts and supports reload), `KeychainBackend` + `MacOsSecurityCliBackend` + `OsKeychainVault`, `ExternalKmsBackend` + `ExternalKmsVault`, and `RotatingVault` (`Arc<RwLock<Arc<dyn Vault>>>`) for hot credential rotation without process restart (`SEC-040`).
3. **Structured secret redaction (`crates/gap-sec/src/vault/redactor.rs`, `mod.rs`):**
   - Implemented `Redactor` (`register_secret`, `redact_text`, `redact_log`, `redact_error_message`, `redact_trace_attributes`, `redact_metric_labels`, `sanitize_enricher_input`) scrubbing registered canary values alongside Bearer tokens, JWTs, PEM private key blocks, common cloud API key prefixes, URL userinfo credentials, and sensitive JSON/KV fields (`SEC-041`, `SEC-042`, `INV-15`).
4. **Tests (`crates/gap-sec/src/vault/tests.rs`, `tests/security/secrets/secret_canary.rs`, `crates/gap-server/tests/secret_canary.rs`):**
   - Added unit tests covering `SecretString`/`SecretBytes`, `FileVault` permission enforcement (`0600`), `EnvVault`/`OsKeychainVault`/`ExternalKmsVault`/`RotatingVault` hot rotation, and `Redactor` scrubbing.
   - Added 7-canary end-to-end leak verification across `SecretString` formatting, logs, OTel span attributes, `GapError`, `NgcErrorInfo`, metric labels, `Redactor::sanitize_enricher_input`, and `gap_ingest::enrich::build_isolated_enrichment_prompt` (`TM-18`).
