## Summary of Changes
1. **`crates/gap-s1/src/candle/mmap.rs` & `docs/UNSAFE.md`**: Implemented POSIX read-only `MAP_PRIVATE` file mapping (`MmapBytes`) with regular-file, non-zero size, `isize::MAX`, and `MAP_FAILED`/`NULL` guards, safe `Send`/`Sync` markers, and clean `munmap` drop. Recorded `UNS-001`..`UNS-005` in `docs/UNSAFE.md`.
2. **`crates/gap-s1/src/candle/{json.rs, sha256.rs, safetensors.rs}`**: Added dependency-free RFC 8259 JSON parser (bounded depth `64`), FIPS 180-4 SHA-256 hex digest, IEEE-754 binary16/binary32 codecs, bounds-checked `SafeTensorsArchive::load_mmap`/`from_bytes`, and deterministic `serialize_safetensors`.
3. **`crates/gap-s1/src/candle/{tokenizer.rs, sequence.rs}`**: Added `LayaTokenizer` (`builtin_default` + HuggingFace `vocab.json` WordPiece without special-ID forgery) and `SequenceBuilder` enforcing `RTE-020` query/option sanitization, `RTE-042` fixed sink phrasing, `[MASK]` marker preservation across `n_options`, and `max(8, floor(0.8 * head_max_len / n_options))` per-option budgets.
4. **`crates/gap-s1/src/candle/{model.rs, mod.rs}` & `crates/gap-s1/src/lib.rs`**: Implemented `LayaCandle` (ModernBERT encoder with local/global RoPE + GeGLU + LayerNorm, 2-layer Transformer decision head, `[MASK]` marker gather, choice/score/NoUL MLPs), double-precision `forward_f64_reference`, `GoldenFixtureScorer`, calibrated checkpoint builder, and `gap_route::DecisionBackend` implementation while preserving `ort` and `sidecar` stubs in `lib.rs`.
5. **`crates/gap-s1/tests/golden/main.rs`**: Added 4 integration tests covering all 210 fixture cases in `tests/fixtures/laya_golden/cases.json` for `F32` (`<= 1e-3`) and `F16` (`<= 5e-2`) logit parity and `>= 99.5%` argmax parity, special-token sanitization, and corrupt/truncated safetensors rejection.
