## What the kit is

A black-box kit over the gRPC binding. 13 checks (`describe.valid`, `describe.stable`, `health`, `foreach.correctness`,
`foreach.n_plus_one`, `query.order`, `deadline`, `cancel`, `mutate.idempotency`, `mutate.dry_run`, `page.stability`,
`errors.mapping`, `limits.response_size`); each ends pass, fail or skip. A skip is `not_applicable` (capability not advertised)
or `not_covered` (advertised, but the profile cannot probe it); `KitReport::compatible()` is false for a failure and for an
uncovered capability (NGC-091: "all applicable fixtures pass, capability-gated"). Connector-specific probe data is a profile,
`.toml` on purpose: the fixture loader reads every `*.json` under `conformance/` and rejects unknown keys. Deadline and cancel are
proved through returned capacity, not only through status codes, because an SDK-hosted server drops the connector future itself
and would hide a connector that keeps working for callers that left.

## Risks and follow-ups

* **Plan inconsistency for WP-M1-11 and WP-M3-05.** Their acceptance commands are `cargo run -p gap-conformance -- --connector-kit --spawn
  fixtures openapi|sql`. The kit takes `--connector <addr>`; `--spawn` is a separate, not yet implemented mode (WP-M1-12/13). With the
  current CLI that command exits 2 ("needs --connector and --profile"). Either those WPs start their connector in-process and call
  `ngc_kit::run_kit` from a test (recommended, it is what the self-test does), or `--spawn` grows a connector variant. Not changed here.
* **Only SDK-hosted connectors were tested.** The kit never ran against a server that is not built on `gap-ngc-sdk`. Checks that an SDK
  core masks (a wrong code on deadline, an over-long per-index message) are covered by pure-function tests or accepted as
  equivalent (E15); a first non-SDK connector may expose assumptions.
* **`--connector` is plain-text TCP only.** TLS and unix sockets are not supported by the kit's client yet (the SDK client can do
  unix sockets; `ngc_kit::connect` does not wire it). `https://` is refused with a clear message.
* **Run on an otherwise idle connector.** `deadline` and `cancel` count slots; other callers make them flake by design.
* **Not observable black-box, documented in conformance/ngc/README.md:** cursor expiry of 10 minutes (NGC-022), field-level scope
  filtering (NGC-024), 24 h idempotency retention, the `Describe` p95 unless `describe_budget_ms` is set.
* `cargo deny` advisories were not run (network).
