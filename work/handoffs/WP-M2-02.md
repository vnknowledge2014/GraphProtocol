1. **Dependencies (`adapters/gap-ngc-code/Cargo.toml`, `Cargo.lock`):**
   - Wired offline-vendored workspace dependencies (`blake3`, `futures-util`, `gap-core`, `gap-ngc-sdk`, `gap-proto`, `gap-store`, `prost-types`, `regex`, `serde`, `serde_json`, `thiserror`, `tokio`, `tracing`, `uuid`; dev: `proptest`, `tempfile`, `tokio`).
2. **Schema Model, Summaries & SCIP Importer (`adapters/gap-ngc-code/src/model.rs`):**
   - Defined all 7 canonical node categories (`Repo`, `File`, `Module`, `Symbol`, `Doc`, `Test`, `Concept`), `SymbolKind` / `DocKind` sub-classifications, all 11 edge predicates (`DEFINES`, `CONTAINS`, `IMPORTS`, `CALLS`, `IMPLEMENTS`, `EXTENDS`, `REFERENCES`, `DOCUMENTS`, `TESTS`, `DEPENDS_ON`, `SUPERSEDES`), and pinned 1.0 grammar version constants (`GRAMMAR_VERSIONS`).

3. **Multi-Language Code & Markdown Extractors (`adapters/gap-ngc-code/src/extract/{mod.rs,code.rs,markdown.rs}`):**
   - Implemented deterministic extractors for all 6 1.0 languages (Rust, TypeScript/JavaScript, Python, Go, Java) plus Markdown (heading hierarchy, ADR `Concept` nodes, `DOCUMENTS` code mentions, `REFERENCES` links, and `Supersedes:` `EDGE_SUPERSEDES` directives), with NUL-byte/UTF-8 and balanced-structure validation isolating single-file parse failures without aborting sibling files (`ING-061`).
4. **Incremental Indexer & Native-Traverse Connector (`adapters/gap-ngc-code/src/{indexer.rs,connector.rs,lib.rs}`):**
   - Implemented `CodeIndexer<S: ContextStore>` with configurable `debounce_ms` (`500` ms default), deterministic sorted walk, `blake3` incremental change detection, removed/stale-node tombstoning via `ContextStore::tombstone_node`, chunked `put_batch <= 10_000`, `ScopeSpec::Global`, cross-file symbol/module/doc/test resolution, and reproducible `export_golden_snapshot`.
   - Implemented `CodeGraphConnector<S: ContextStore>` implementing `gap_ngc_sdk::connector::Connector` (`describe` advertising `native_traverse = true`, `as_of = true`, `foreach_batch = true`, `limits.max_page_size = 1_000`, `MetaSummary`; `query` supporting `code_traverse`, `code_node`, `code_search`, `code_callers` with `ING-064` bounds `maxDepth 1..=16`, `first 1..=1_000`, `visitedCap 1..=1_000_000`, `limit 1..=100`, `WEIGHTED`, `asOf`, `returnFields` slicing, and `foreach` batching with `upstream_calls = 1`; plus `health`).
5. **Golden Fixtures & Integration Tests (`tests/fixtures/repos/polyglot_sample/**`, `tests/fixtures/repos/polyglot_sample.golden.json`, `adapters/gap-ngc-code/tests/code_indexer.rs`):**

   - Added 5 integration tests (`ing_060`..`ing_064`) verifying category/predicate completeness, SCIP `EXACT` vs `HEURISTIC`, malformed-file failure isolation, `blake3` incremental hashing & `as_of` tombstone retention, golden snapshot reproducibility, `<= 40`-token summaries & `<= 15%` `returnFields` token efficiency, `foreach` per-index isolation, cursor pagination, and `ING-064` bounds errors.
