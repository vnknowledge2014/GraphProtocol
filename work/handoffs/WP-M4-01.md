# Handoff: WP-M4-01 (`gap-ingest` foundations: CISG, Extractor trait, worker process framework)

## Summary of Changes
- **`crates/gap-ingest/src/cisg/mod.rs`:**
  - Implemented Canonical Intermediate Schema Graph (`Cisg`, `SourceRef`, `ExtractorInfo`, `TypeDef`, `FieldDef`, `TypeRef`, `ArgDef`, `Example`, `Pagination`, `OperationDef`, `KeyDef`, `FieldRef`, `JoinCardinality`, `JoinEvidence`, `CandidateJoin`, `DocBlob`, `CisgValue`) using `gap_core::snapshot::{OpKind, Protocol, SideEffectLevel}`.
  - Implemented deterministic `canonicalize()`, RFC 8785 JCS canonical JSON encoding, and FIPS 180-4 SHA-256 `cisg_hash()` (`ING-010`).
  - Implemented `UntrustedText` (`text`, `sanitized`, `lint: LintStatus`, `hash`) stripping bidirectional overrides/control characters and flagging suspicious prompt-injection markers so only `.sanitized()` flows downstream (`ING-020`).
  - Defined `Extractor` trait, `SourceHandle` (size-bounded in-memory input), `ExtractLimits`, and typed `ExtractError` (`TooLarge`, `DepthExceeded`, `TooManyItems`, `Timeout`, `Malformed`, `Unsupported`) (`ING-011`, `ING-012`).
- **`crates/gap-ingest/src/fetch/mod.rs`:**
  - Defined `SourceFetcher`, `FetchLimits`, `FetchedSource`, `FetchError`, and `DenyAllSourceFetcher` rejecting network URLs by default until `EgressGuard` (`WP-M6-08`) lands (`ING-011`).
- **`crates/gap-ingest/src/worker/mod.rs`:**
  - Implemented `WorkerLimits`, `WorkerPoolConfig`, RAII `WorkerMetricsSnapshot` (`active_for_tenant`, `gap_ingest_backlog` per `ING-071`), `WorkerReport`, `WorkerOutcome<T>`, and `WorkerPool` supporting both panic/timeout-isolated execution (`run_isolated`) and scrubbed-env, absolute-path subprocess execution (`run_command_isolated` with `wall_clock_timeout` kill and bounded stdout/stderr pipes per `ING-070`, `ING-012`, `ADR-013`).
- **`crates/gap-ingest/src/lib.rs`:**
  - Added curated re-exports across `cisg`, `fetch`, and `worker`.
