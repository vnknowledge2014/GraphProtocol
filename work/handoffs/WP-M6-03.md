# Handoff: WP-M6-03 — gap-a2a: A2A v1.0 Inbound Binding & Outbound Connector

## Summary
Completed the `gap-a2a` A2A `v1.0` protocol adapter (`CMP-020`..`CMP-023`, `INV-15`, `INV-20`, `ADR-016`, `ADR-017`), including deterministic `AgentCard` generation and JWS signing over RFC 8785 JCS JSON, inbound HTTP+JSON / JSON-RPC 2.0 / SSE facade (`HttpModule`), outbound `A2aPeerConnector` (`Connector`) with bearer stripping and trace loop detection, wire integration tests, and `Facade-A2A` conformance fixtures.

## Changes
- `adapters/gap-a2a/src/wire.rs`: `A2aTaskState` (`TASK_STATE_*` wire mapping + `TASK_STATE_UNSPECIFIED` rejection), `A2aRole`, tagless `A2aPart` union, `A2aMessage`, `A2aArtifact`, `A2aTask`, `A2aStreamEvent` SSE encoders, JSON-RPC 2.0 envelope helpers, and `TraceExtension` (`https://gap-protocol.org/ext/trace/v1`) hop/cycle validation.
- `adapters/gap-a2a/src/card.rs`: deterministic `build_agent_card` omitting `TrustTier::T2` branch details (`INV-07`), `AgentInterface` bindings (`JSONRPC`, `HTTP+JSON`, `GRPC`), and Ed25519 detached JWS signing/verification over canonical unsigned JCS JSON (`sign_agent_card`, `verify_agent_card_signatures`).
- `adapters/gap-a2a/src/inbound.rs`: `A2aTaskBackend`, `InMemoryA2aBackend`, and `A2aFacade` (`HttpModule`) serving `/.well-known/agent-card.json`, `/message:send`, `/message:stream`, `/tasks`, `/tasks/{id}`, `/tasks/{id}:cancel`, `/tasks/{id}:subscribe`, and `/a2a`; text-only -> `DiscoveryService::resolve` artifact (`TASK_STATE_COMPLETED` / `TASK_STATE_INPUT_REQUIRED` resumed via `message.taskId`), data-part `{gapql, variables}` -> task, tenant isolation via `ctx.tenant_scope()`, and RFC/google.rpc error mapping.
- `adapters/gap-a2a/src/outbound.rs` and `lib.rs`: `A2aPeerConnector` mapping skills to `OpKind::Task` operations (`SideEffectHint::SideEffectUnspecified`), echoing `AgentInterface.tenant`, stripping client `authorization` headers (`INV-15`), propagating `CallContext` + `CallScope` trace hops/paths (`INV-20`), `1 s -> 10 s` backoff `poll_task_until_settled`, and `decode_stream_events`.
- `adapters/gap-a2a/src/tests.rs` & `adapters/gap-a2a/tests/loop_and_wire.rs`: unit and two-GAP-node mutual delegation loop detection tests.
- `conformance/a2a/{README.md,001..005_*.json}`: 5 `Facade-A2A` conformance fixtures covering `CMP-020`..`CMP-023`, `GQL-001`, `GQL-002`, and `GQL-050`.
