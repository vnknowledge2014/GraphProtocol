## Implemented Deliverables

1. **Active-only JoinGraph & Cycle/Batchability Checks (`crates/gap-core/src/joingraph/mod.rs`):**
   - Added `JoinGraph::from_active_only` (filters strictly to `JoinStatus::Active` edges sorted deterministically by `(id, source_type, field_name)`), `JoinGraph::active_edges_for_type`, `JoinGraph::lookup` (`INV-06`, `GQL-031`).
   - Added `JoinGraph::validate_join_cycles` enforcing `MAX_JOIN_DEPTH = 16` (`GQL-040`, `GQL-042`) across active edges and rejecting unbounded active cycles with `ErrorCode::CycleUnbounded` (`GAP_CYCLE_UNBOUNDED`).
   - Added `validate_edge_batchability` rejecting `MANY_TO_MANY` (`RUN-021`), empty keys, invalid `max_depth`, and non-batchable edges where `allow_per_key_fallback = false` with `ErrorCode::JoinNotBatchable` (`RUN-027`, `INV-18`).

2. **Pushdown Capability Negotiation & Remote Predicate Planning (`crates/gap-plan/src/pushdown/mod.rs`):**
   - Added `DEFAULT_FALLBACK_ROWS = 10_000`, `DEFAULT_MAX_PUSHDOWN_KEYS = 5_000`, `PredicateExpr` (with `to_canonical_json`), `PushdownCapabilities` (`from_snapshot_capabilities` + builder helpers), `RequestedPushdown`, `PushdownWarning`, and `NegotiatedPushdown`.
   - Implemented `negotiate_pushdown` (`RUN-012`, `NGC-023`): offloads predicates, ordering, projections, and limits only when remote capabilities support them; prevents premature remote `LIMIT` before local filter/sort; emits `GAP_PUSHDOWN_FALLBACK` bounded fallback warnings within `max_fallback_rows` or rejects requests exceeding the bounded cap.
   - Implemented `plan_remote_predicate_keys` (`RUN-023`, `RUN-010`): deduplicates and canonically sorts join keys, chunks by `max_keys_per_batch`, and emits deterministic `IN` (or singleton `EQ`) pushdown predicates.

3. **Cross-branch Join Planner (`crates/gap-plan/src/join/mod.rs`):**
   - Implemented `map_join_cardinality` (`RUN-021`, rejecting `MANY_TO_MANY`), `select_join_strategy` (`ForeachBatch` preferred, `RemotePredicate` fallback for single-key `IN`-capable branches, explicit `GAP_JOIN_NOT_BATCHABLE` rejection when neither is supported — `RUN-023`, `RUN-027`, `INV-18`).
   - Implemented `validate_snapshot_joins`, `plan_join_edge`, and `plan_joins_for_fetch` (`RUN-010`, `RUN-013`, `GQL-042`, `INV-06`): ignores non-`Active` edges (`Proposed`, `Canary`, `Quarantined`, `Disabled`), enforces depth bounds (`DepthExceeded`), checks target branch health (`BranchQuarantined`, `BranchUnavailable`), negotiates RHS pushdown, and folds multiple joins in canonical deterministic order.
