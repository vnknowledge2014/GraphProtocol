## Summary of Changes

1. **BSL-1.1 Isolation & Documentation ([crates/gap-store/src/surreal/mod.rs](../../crates/gap-store/src/surreal/mod.rs)):**
   - Kept the SurrealDB `3.x` backend strictly behind opt-in compile-time feature `store-surreal` (disabled in default builds) with zero BSL-1.1 Rust crates added to `Cargo.toml` or `Cargo.lock` (`ADR-002`, `ADR-020`, `OPS-042`).
2. **Tenant-Keyed SurrealQL Schema & Transports ([schema.rs](../../crates/gap-store/src/surreal/schema.rs), [transport.rs](../../crates/gap-store/src/surreal/transport.rs)):**
   - Defined `SURREAL_SCHEMA_SURREALQL` (`SCHEMAFULL` tables `nodes`, `edges`, `tenant_stats`, `tasks`, `task_events` with leading `tenant` composite indexes per `INV-09`), collision-resistant `tenant_record_key`, and alphanumeric token sanitization.
   - Implemented `SurrealConfig`, pluggable `SurrealTransport`, stdlib `HttpSurrealTransport` (`POST /sql` with `NS`/`DB` headers and Basic auth), and atomic `InMemorySurrealEngine`.
3. **Full `ContextStore`, `ContextMaintenance`, and `TaskStore` Parity ([context.rs](../../crates/gap-store/src/surreal/context.rs), [tasks.rs](../../crates/gap-store/src/surreal/tasks.rs)):**
   - Implemented bi-temporal node/edge storage, UUIDv7 minting for `id: None` creates, non-`Global` `NotFound` oracle prevention (`ING-065`), scope visibility (`Global`, `Private`, `Group`, `Task`, `Ephemeral`), rollback-safe `put_batch`, bounded traversals (`Bfs`, `Dfs`, `Shortest`, `Weighted` + stateless `TraverseResume`), conjunctive TF/BM25 search, maintenance tombstoning/purging (`ING-066`), and `SurrealTaskStore` / `SurrealContextStore` `TaskStore` lifecycle methods.
