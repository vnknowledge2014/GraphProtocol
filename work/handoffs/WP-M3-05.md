## Summary

* Implemented `gap-ngc-sql` (`adapters/gap-ngc-sql/src/{lib,config,driver,cursor,template,sketch,connector}.rs`) providing parameterized read-only SQLite and PostgreSQL dialect query execution behind `gap_ngc_sdk::Connector`.
* Enforced identifier allow-lists (no user-supplied SQL fragments or dynamic identifiers), typed `SqlParam` bindings (`?` for SQLite, `$N` + `= ANY($1)` for PostgreSQL), compound pushdown predicates (`AND`, `OR`, `NOT`, `EXISTS`, `P_EQ..P_IN` with strict `INVALID_ARGUMENT` rejection for unadvertised `P_CONTAINS`), field projection, deterministic key tie-breaking, bound expiring pagination cursors (`>= 10 min` TTL), and response size / row-cap truncation.
* Enforced read-only execution (`SQLITE_OPEN_READ_ONLY` and `PRAGMA query_only = ON`) plus cancellation/deadline enforcement via RAII `InterruptWatchdog` + `CancelBlockingQuery` using `rusqlite::InterruptHandle`.
* Implemented `Sketch` bottom-k salted `blake3` hashing (`exact`, `null_ratio`, `uniqueness_ratio`, `value_kind`).
* Added SQLite fixture `tests/fixtures/sql/shop.sql`, NGC conformance profile `conformance/ngc/sql.kit.toml`, black-box kit runner test `crates/gap-conformance/tests/ngc_kit_sql.rs`, and 7 integration/adversarial tests in `adapters/gap-ngc-sql/tests/sql_connector.rs`.
