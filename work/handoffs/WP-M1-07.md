Design notes & brief recordings (`work/context/m1-07-brief.md`):
  1. [`ConnectorRegistry` v0 pooling & lock-free read path (`INV-02`, `NGC-071`, `Brief §3.1`)]:
     `ConnectorRegistry` stores an immutable `BTreeMap<BranchUid, RegisteredBranch>` with zero
     `Mutex`/`RwLock`/`DashMap` primitives anywhere in `crates/gap-exec/src/**` (verified statically
     in `inv_02_connector_registry_has_no_locks_on_read_path`). In v0, pooling is one multiplexed
     `Arc<dyn BranchClient>` per branch paired with a `tokio::sync::Semaphore(max_in_flight)`
     acquired strictly via `try_acquire_owned` (`GAP_OVERLOADED` fast-fail, never queueing) and held
     across stream opening and consumption via `PermitGuardedStream`.
  2. [`ExecResponse.extensions` shape (`work/work-packages.toml` vs `Brief §3.2`)]:
     `work/work-packages.toml` names `extensions.gap.{generation,cost,partial}` (`GQL-050` wire JSON
     envelope), whereas `Brief §3.2` specifies the in-process Rust struct `ExecResponse { data,
     errors, extensions: GapExtensions { generation, cost, partial } }`. `ExecResponse` implements
     the concrete typed `GapExtensions` field from `Brief §3.2`; `WP-M1-08` (`gap-transport`) wraps
     `GapExtensions` under `"extensions": { "gap": ... }` when serializing the HTTP response body.
  3. [`RUN-061` authorization & PII redaction seam (`Brief §1`)]:
     `ResponseRedactor` (`NoopResponseRedactor` default) is injected into `ExecLayer` and invoked on
     every projected object field and root field in `assembly.rs`, reconciling any byte delta against
     `LocalSizeTracker` and propagating `GAP_FORBIDDEN` + `NullBubble` if a non-null field is
     removed (`None`).
  4. [Incremental response-size budget & Protobuf `NumberValue` normalization (`RUN-060`)]:
     `ResponseSizeBudget` (`AtomicUsize` + `abort_cancel`) tracks exact compact UTF-8 JSON bytes as
     rows stream in, while per-fetch `LocalSizeTracker` checkpoints refund only that fetch's bytes
     when a nullable ancestor absorbs a `NonNullViolation` without disturbing concurrent `Parallel`
     fetches. Exceeding `max_response_bytes` cancels `abort_cancel` immediately across all active
     fetches and reports the truncation `path`. Protobuf `f64` `NumberValue` integers are normalized
     to integer `serde_json::Number` for GraphQL `Int` and integer `JSON` scalars so byte accounting
     matches `serde_json::to_vec` byte-for-byte.
  5. [`.git/tmp-cargo-home` left in place (`Brief §2`)]:
     Per protocol instructions, `.git/tmp-cargo-home` was used for offline Cargo commands and is
     intentionally left in place for the reviewer.
