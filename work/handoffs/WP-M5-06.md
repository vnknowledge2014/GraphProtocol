## Summary of Changes
1. **`crates/gap-s1/src/sidecar/{egress.rs, protocol.rs, server.rs, mod.rs, tests.rs}`**:
   - Implemented pure-`std` `HttpSidecar` (`DecisionBackend`, `score_choice_sync`, `score_choice_batch`) speaking HTTP/1.1 `POST /v1/systemone` and `POST /v1/systemone/batch` compatible with `omni decide --endpoint`, with bounded response parsing (`Content-Length` + chunked transfer decoding, `DEFAULT_MAX_RESPONSE_BYTES`), TCP connect/write/read deadlines (`RTE-044`), and DNS-pinning TOCTOU mitigation.
   - Implemented fail-closed `EgressGuardHook` / `DefaultSidecarEgressGuard` blocking non-`http://` schemes, userinfo, query/fragment/traversal segments, cloud metadata hosts/IPs (`169.254.169.254`, `100.100.100.200`, `fd00:ec2::254`, `metadata.google.internal`), RFC1918/ULA private ranges, and unpermitted loopback targets.
   - Added `LoopbackSidecarServer` golden oracle wrapping any `Arc<dyn DecisionBackend>` and 3 `sidecar` tests covering single+batch `LayaCandle` oracle parity, read timeout + body cap rejection, and egress blocking.
2. **`crates/gap-s1/src/ort/{mod.rs, tests.rs}`**:
   - Preserved zero-`unsafe` build hygiene (`UNS-001`..`UNS-005` untouched); exported `OrtFeatureDisabled` stub when `s1-ort` is disabled.
   - Behind `--features s1-ort` (pinning `ort = "=2.0.0-rc.15"` contract per `docs/evidence/crate-versions.md`), implemented `OrtExecutionProvider::{Cpu, CoreMl}`, `OrtSessionOptions`, `OrtOptimizationLevel`, `LayaOrt` (`DecisionBackend` with `score_choice_with_timeout`), and `measure_ort_vs_candle`, plus parity (`max |Δlogit| <= 1e-3`) and timeout tests.
   - *(Note on `WP-M5-06` `owns`: `docs/decisions/G-S1.md` is owned by `WP-M5-08`; the CPU vs CoreML fallback vs Candle table below is recorded here for incorporation into `docs/decisions/G-S1.md` during `WP-M5-08`.)*
