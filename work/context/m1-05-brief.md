## 3. Design (binding shape; names inside a module are yours unless stated)

1. **Persistent containers (ARC-005).** In `gap-core::snapshot`: `Snapshot.branches: im::OrdMap<BranchUid, Arc<BranchDescriptor>>` and `Snapshot.groups: im::OrdMap<GroupId, Arc<CapabilityGroup>>` replace the `Arc<BTreeMap<..>>` of WP-M0-08. A new `Snapshot.ownership: Arc<FieldOwnership>` where
   `FieldOwnership` is an immutable `BTreeMap<FieldCoordinate { type_name: String, field: String }, BranchUid>` with `owner(&FieldCoordinate) -> Option<BranchUid>`, `fields_of(BranchUid)` and `len()`. Keep `Snapshot::empty*`, `next_generation` and `PlanCacheKey::from_snapshot` working; update the existing `gap-core` tests (the structural-sharing test must now show that `g2.branches` shares the unchanged
   `Arc<BranchDescriptor>`s and, via `im`, that cloning an `OrdMap` and inserting one branch does not copy the rest: assert `Arc::ptr_eq` on descriptors). `ErrorCode` gains `AmbiguousField` (`GAP_AMBIGUOUS_FIELD`, class composition, not retryable) and `DirectiveIgnored` (`GAP_DIRECTIVE_IGNORED`, class composition, a warning); update `ALL`, the count in its doc and tests, `ErrorClass`, the NGC mapping table: follow the existing pattern for `ReservedName`.
2. **`canonical`** — `canonical_json(&serde_json::Value) -> String` implementing RFC 8785: UTF-16 code-unit key order, the JCS string escaping, ECMAScript `Number::toString` for finite numbers (`-0` is `0`; non-finite is an error). Used for `desc_hash` and `branch_set_hash`. Verify it against the RFC 8785 appendix values you can derive from the text of the RFC and against 
   a table of at least 40 doubles whose ECMAScript spelling you know for certain (powers of ten around the 1e21 and 1e-7 switches, 0.1+0.2, 5e-324, 1.7976931348623157e308, 333333333.3333333, integers up to 2^53): no `f64::to_string` shortcuts. The reviewer cross-checks 100,000 random doubles against Node's `String(x)`.
3. **`compose`** — pure, deterministic, no I/O: `compose(branches: &[BranchInput]) -> Result<Composition, CompositionError>` where `BranchInput { id: BranchId, uid: BranchUid, protocol: Protocol, trust: TrustTier, endpoint: Endpoint, description: gap_proto::ngc::v1::ConnectorDescription, status: BranchStatus }`
   and `Composition { schema: apollo_compiler::validation::Valid<Schema> (or Schema), sdl: String, branches: Vec<Arc<BranchDescriptor>>, ownership: FieldOwnership, warnings: Vec<CompositionWarning>, branch_set_hash: [u8; 32] }`. Rules are RUN-009 (a)..(f); summary:
   * input order is irrelevant: sort by `BranchId`, byte-identical `sdl` and `branch_set_hash` for any permutation; two inputs with the same `BranchId` or `BranchUid` are an error;
   * each branch SDL is parsed with the bounded parser, checked for reserved names (`validate_branch_ast_reserved_names`: `GAP_RESERVED_NAME`), then **namespaced**: every non-root named type defined by the branch becomes `<ns>_<Name>` (`ns` = `BranchId` with `-` replaced by `_`) and every reference to it (field types, argument types, input fields, `implements`, union members,
     directive arguments that name types are not touched) is rewritten; built-in GAP types, the standard scalars and GAP directives are shared and never renamed; the branch's `Query`/`Mutation`/`Subscription` object definitions are merged onto the built-in root types (reuse `normalize_branch_root_definitions` through `gap-ql`; if it is `pub(crate)` there, you may not change `gap-ql`: rebuild the few lines in `gap-snapshot`);
   * `@branch(id, uid, protocol, trust)` is attached to each root field and each object type of the branch; authored `@branch`, `@capabilityGroup`, `@provenance`, `@join(status:)` are removed and reported as `GAP_DIRECTIVE_IGNORED` warnings (GQL-030); `@sideEffect` on a `T2` branch is forced to `UNKNOWN` (GQL-032);
   * ownership: every root field belongs to its branch; two branches defining the same root field, or a produced type name that exists twice, is `GAP_AMBIGUOUS_FIELD` naming both branches; a branch defining `gap`, `__search`, `__metaGraph` or any `__`-prefixed name is `GAP_RESERVED_NAME`;
   * operations: each `OperationDescriptor` of the description must match one root field of the root type of its kind (QUERY/MUTATION/SUBSCRIPTION) and every branch root field must have an operation; mismatch is `GAP_VALIDATION_ERROR` with the branch and the field. The resulting `BranchDescriptor.operations` carry `desc_hash` = `blake3(canonical_json({name, description, input_schema, output_schema, annotations}))` computed by GAP (never the connector's hash, NGC-011),
     `sdl` = the field's SDL signature after namespacing, `group` = a per-operation `GroupId` (blake3-128 hex of the canonical signature), `side_effect` from the hint with `verified: false` (ADR-015), `kind`, `idempotent`, `cost` from `cost_weight`;
   * `BranchDescriptor.pinned_desc_hash` = `blake3` over the sorted operation `desc_hash`es; `spec_hash` from the description; `capabilities`/`limits` converted from the proto (`limits.max_batch_size`, `max_in_flight`, `default_timeout_ms`, `max_response_bytes`); `synopsis` from `meta.synopsis_hint` clipped to 90 bytes on a char boundary;
   * `branch_set_hash` = `blake3` over `canonical_json` of the sorted `[(uid, pinned_desc_hash, status)]`.
   The supergraph must pass `apollo-compiler` validation and contain the GAP built-ins exactly once; a composition with zero branches is valid (just the built-ins).
4. **`SnapshotHandle`** (`handle` module) — `new(initial: Snapshot)`, `pin(&self) -> Arc<Snapshot>` (wait-free: `arc_swap::ArcSwap::load_full`, no lock, no allocation), `generation()`, and `publish(&self, next: Snapshot) -> Result<u64, PublishError>`
   (RUN-003/004 minimal: serialised by one `Mutex<()>`-free mechanism, for example a single-writer compare-and-swap loop with `ArcSwap::rcu`, assert `next.generation == current + 1` else `PublishError::NonMonotonic`, `format_version` supported else `PublishError::UnsupportedFormat`; the previous `Arc` is dropped **off the caller's thread** is out of scope, but `publish` itself must not hold any lock a reader can touch (INV-16: measure and assert in a test that
   a publish with 1 unchanged and 1 changed branch of 1,000 takes under 1 ms on the test machine, as a smoke test with a generous bound, not a benchmark). `Snapshot::next_generation` is the supported way to derive the next generation. A small `SnapshotBuilder` that takes a `Composition` plus the current snapshot and produces the next `Snapshot` (sharing unchanged `Arc<BranchDescriptor>`s when a branch's `pinned_desc_hash`, `status`, and namespaced SDL are unchanged: compare and reuse the old `Arc`).
5. Crate header as the other crates (`forbid(unsafe_code)`, the clippy denies; tests may use `expect`). The existing placeholder modules (`diff`, `groups`, `incremental`, `publisher`, `rollback`) stay as they are.

## 4. Tests (binding)

* **inv_01_request_pins_single_generation**: a "request" pins once and keeps reading `branches`, `schema`, `ownership` while a writer publishes 100 generations on another thread; every read of the request sees the pinned generation's data only (compare content, not just numbers), and the pinned `Arc` stays alive after the handle moved on.
* **inv_02_no_lock_on_read_path**: (a) a static check: the source of `handle.rs` read path (`pin`, `generation`) contains no `Mutex`, `RwLock`, `.lock(`, `.read(`, `.write(`, `await` (a test that greps the file text between two markers you place, so the check fails if someone adds a lock); (b) a stress test on a multi-thread runtime: 32 reader threads pin in a tight loop for a bounded count while a writer publishes, no reader ever blocks longer than 50 ms (generous) and every pinned generation is one that was published.
* **compose_***: golden SDL of two realistic branches (use the shop document's generated SDL and a hand-written second branch that defines the same type name `Customer`: after composition both exist as `shop_Customer` and `crm_Customer`); permutation determinism (all orderings of 4 branches: identical `sdl` and hash); namespacing rewrite coverage for every reference position (field type, list/non-null wrappers, argument type, input object field, `implements`, union member, interface field) with a negative check that built-in names are untouched;
  `GAP_RESERVED_NAME` (`gap` root field, `__x` type, type named like a built-in such as `Query`-less `SearchResult`); `GAP_AMBIGUOUS_FIELD` (same root field in two branches; the `a`/`b_C` versus `a_b`/`C` collision) with both branch ids in the message; operation/field mismatch both ways; `@branch` and friends stripped with `GAP_DIRECTIVE_IGNORED` warnings and the composer's `@branch` present on every root field; `T2` `@sideEffect` forced to `UNKNOWN`; ownership map equals the `@branch` directives of the schema (property test over generated branches);
  `desc_hash` changes when any of the five hashed fields changes and ignores a connector-provided hash; `branch_set_hash` changes with status; zero-branch composition valid; a hostile branch (10,000 types, deep wrapper nesting, 1 MiB description) ends in a bounded `Err` or `Ok`.
* **canonical_***: the table of section 3.2, key ordering by UTF-16 code units (a key with a supplementary character versus a BMP character above U+D800), escaping table, `-0`, large integers, nested structure, rejection of NaN/inf.
* **snapshot containers**: the `gap-core` tests of 3.1; `SnapshotBuilder` reuses the unchanged `Arc<BranchDescriptor>` (`Arc::ptr_eq`) and replaces only the changed one; two generations built from permuted inputs have equal `branch_set_hash`.
* Every test carries `// spec: <ID>` (ARC-005, ARC-006, RUN-003, RUN-009, RUN-011, GQL-004, GQL-030, GQL-032, INV-01, INV-02, INV-16, NGC-011, ADR-015 where it applies) and the traceability tool stays green; deterministic, 3 runs without flakiness.
