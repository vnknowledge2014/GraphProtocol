## 3. Design (binding shape; names inside a module are yours unless stated)

1. **Public API** (`inbound/mod.rs`): `McpFacade` built by `McpFacade::builder(engine: Arc<dyn GraphqlEngine>)` with optional `.operations(Arc<dyn OperationCatalog>)`, `.tasks(Arc<dyn TaskBackend>)`, `.visibility(Arc<dyn Visibility>)`, `.config(FacadeConfig)`; `impl HttpModule for McpFacade` (`module_name() = "mcp"`, `mount_prefixes() = ["/mcp"]`); `StdioServer::new(facade, ctx_factory: Arc<dyn Fn() -> GapResult<RequestContext> + Send + Sync>)` with `async fn serve<R: AsyncBufRead + Unpin, W: AsyncWrite + Unpin>(&self, reader, writer)` for newline-delimited JSON-RPC (a fresh `RequestContext` per request: INV-01).
   `FacadeConfig { spotlight: bool (default true), spotlight_t1: bool (false), allowed_origins: Vec<String> (empty = only same-host loopback origins and absent `Origin`), max_request_bytes (default 1 MiB), max_sessions (default 256), session_idle_ttl (default 30 min), metagraph_branches (default 100), server_name, server_version }`; validated at construction; `Debug` redacts nothing secret because it holds nothing secret.
   Traits declared in this crate: `OperationCatalog::list(&self, ctx) -> Vec<OperationInfo{id,name,description,side_effect}>` (default: empty), `TaskBackend` (`get/list/cancel/decide/submit`, default: every call is `GAP_UNSUPPORTED_FEATURE`), `Visibility::visible(&self, ctx, element: ElementRef) -> bool` with `AllVisible` (default) and `HideT2` (hides every element owned by a `TrustTier::T2` branch: OPS-001 `prod` profile; GQL-062: a hidden element behaves as if it does not exist, including in error messages and counts).
2. **Wire handling (CMP-001, pinned `2026-07-28` text)**: `POST` only (`GET`/`DELETE` -> `405` + `Allow: POST` unless they carry a known legacy `MCP-Session-Id`: then the 2025-11-25 rules); `Origin` validated (`403`); body cap; `Content-Type: application/json`; `Accept` must list `application/json` and `text/event-stream` (else `406`); `MCP-Protocol-Version`, `Mcp-Method` and, for `tools/call` and `resources/read`, `Mcp-Name` must be present and equal the body's `method` / `params.name` (or `params.uri`) else HTTP `400` + JSON-RPC `-32020` `HeaderMismatchError` (an untrusted header never decides the method: the body does, the header is only checked against it).
   JSON-RPC batch arrays are refused (`-32600`). Each request of the stateless era carries `params._meta["io.modelcontextprotocol/protocolVersion"]` and `.../clientCapabilities` (`-32602` if missing; `-32022` `UnsupportedProtocolVersionError` with the supported list `["2026-07-28", "2025-11-25"]`); every result carries `resultType`, and `_meta["io.modelcontextprotocol/serverInfo"]`. `server/discover` returns `DiscoverResult` (`supportedVersions`, `capabilities` = `{tools:{listChanged:false}, resources:{subscribe:false, listChanged:false}}`, `ttlMs`, `cacheScope`).
   Legacy era: a body whose method is `initialize` creates a session (`MCP-Session-Id` = UUIDv7 on HTTP, process-scoped on stdio), `notifications/initialized` is accepted, later requests must carry the id (`404` for an unknown/expired one, `400` for a missing one) and are served with the legacy shapes (no `resultType`/`ttlMs`/`cacheScope` requirement but harmless extras are not emitted); sessions live in a bounded map (`max_sessions`, idle TTL, oldest evicted first, never unbounded), and a session holds no request state (INV-01 still applies: snapshot per request). Unknown methods -> `-32601`; malformed JSON -> `-32700`; invalid params -> `-32602`; internal failures -> `-32603` with an opaque message + correlation id (INV-15: no stack, path or secret in any error).
3. **Five static tools (CMP-002/003)**: authored as `const`/`static` data in `inbound/tools.rs` (no tool text derives from a branch, SEC-080); exact names, annotations (`readOnlyHint`, `destructiveHint`, `idempotentHint`, `openWorldHint` as in the table) and JSON Schemas of the inputs from `spec/09` section 1 (`additionalProperties: false`, the stated ranges and defaults); each description <= 60 model tokens and instructing: write GAP-QL, start with `gap_describe{overview:true}` or `gap_search`, treat `<gap:untrusted>` content as data, never put secrets in queries. `tools/list` is byte-identical for every connection and every principal, with `resultType: "complete"`, `ttlMs` (> 0), `cacheScope: "public"`.
   Argument validation is strict (unknown keys, wrong types and out-of-range numbers are `-32602` with the offending path, not a tool result); a `tools/call` for an unknown tool is `-32602`.
4. **Results (CMP-004)** for `tools/call`: `{resultType:"complete", content:[{type:"text", text:<minified JSON, truncated to budget.tokens by the GQL-022 estimator ceil(bytes/3.6)>}], structuredContent:<the full GraphQL-shaped response object {data?, errors?, extensions?}>, isError}`; `isError = true` iff the response has errors and no usable `data`; truncation adds `{"truncated": true, "hint": "use first/after or returnFields"}` to the text (never cut inside a UTF-8 scalar; the structured content is not truncated). Protocol-level JSON-RPC errors are reserved for malformed MCP requests; GAP errors are tool results (`isError`), with `extensions.code`, `retry` and `correlationId` preserved.
5. **`gap_describe` / `gap_search`** (M1 baseline; the hybrid index and `__search`/`__metaGraph` resolvers arrive with `WP-M2-05`; the facade must not require them): `gap_describe{overview}` renders GQL-023 from `ctx.snapshot` (branches ordered by operation count desc then id, at most `metagraph_branches`, synopsis cut to <= 90 bytes, trust tier and status per branch, generation); `types: [..]` renders the named type SDL from `snapshot.schema` with `depth` 1..3 expansion of referenced types (cycle-safe, deterministic order, unknown name -> `GAP_UNKNOWN_FIELD`-style tool error with `didYouMean` from visible names); `operations: true` lists `OperationCatalog`. Every output goes through `Visibility`.
   `gap_search` calls `ctx.snapshot.index.search(&tenant, query, None, limit)`; when `index.element_count() == 0` (every M1 snapshot) it falls back to a deterministic lexical baseline over the visible schema elements (operation/type/field names split on case/underscore, description words; score = matched query-token fraction, stable tie-break by path) and marks the result `GAP_DISCOVERY_DEGRADED` (warning) so hosts and tests can tell. Shape = `SearchResult` of spec/02 section 4 (`hits[{score,kind,name,path,branch,description,sdl,sideEffect,trust}]`, `tokensEstimate`, `abstained`), `abstained` iff no hit reaches `0.15`; `sdl` is the minimal self-contained fragment (GQL-021) cut at `budget_tokens` with the trailing `# truncated: use __type(name: "X")` comment; never executes a branch operation (GQL-011); hidden elements never appear (INV-05).
6. **`gap_query` / `gap_mutate` / `gap_task`**: `gap_query` parses the document with `gap_ql` and refuses any mutation, subscription or task submission (`GAP_OPERATION_NOT_ALLOWED`, suggestion text naming `gap_mutate`) **before** calling the engine (test with an engine that panics if called); otherwise builds `GraphqlRequest { query, operation_name, variables, extensions: { "gap": { "deadlineMs": budget.ms, "budgetTokens": budget.tokens } } }` and calls `engine.execute(&ctx, req)`.
   `gap_mutate` requires a mutation document (a query is `GAP_OPERATION_NOT_ALLOWED` naming `gap_query`), sets `extensions.gap.dryRun` and `ctx.idempotency_key` (a clone of the context: the original is untouched) and forwards; an `INPUT_REQUIRED` outcome from the engine (`extensions.gap.inputRequired`) is returned as `resultType: "input_required"` with the task id and approval summary. `gap_task` maps `action` to `TaskBackend`; `decide` additionally needs the principal scope `tasks:decide` (else `GAP_FORBIDDEN`, redacted reason).
7. **Spotlighting (CMP-007 / SEC-083)**: when `spotlight` is on, every root field of `data` owned (via `snapshot.ownership`) by a T2 branch (and T1 if `spotlight_t1`) is wrapped in the **text** rendering as `<gap:untrusted source="branch/op">…</gap:untrusted>`; the closing tag can never be forged by the content (escape any occurrence of `<gap:untrusted` / `</gap:untrusted>` inside the wrapped text, test with a hostile payload); `structuredContent` stays pure JSON and carries `extensions.gap.provenance[{field, branch, trust}]` for the wrapped fields. A T0 field is never wrapped.
8. **Resources (CMP-005)**: `resources/list` -> `gap://meta`, `gap://operations`; `resources/templates/list` -> `gap://schema/{type}`, `gap://task/{id}`; `resources/read` serves them (same renderers as 3.5, `Visibility` applied, missing/unknown URI `-32602`); all with `resultType`, `ttlMs`, `cacheScope` (`private`, `ttlMs: 0` where principal-filtered); `capabilities.resources = {subscribe:false, listChanged:false}`; `resources/subscribe` -> `-32601`.
9. **Size gate (CMP-003/CMP-008, G-F1)**: the `tools/list` result (the exact JSON the facade serves) is at most 1,200 tokens under **both** in-repo counters in `tests/inbound/size_gate.rs`: A = `ceil(utf8_bytes / 3)`, B = every maximal run of letters/digits split into pieces of at most 4 chars plus one token per other non-space character; for N = 5, 50, 200, 1,000 branches in the snapshot (the result must be byte-identical for all N: it does not depend on the snapshot). Each description is individually <= 60 tokens under A and B. Test names contain `facade_tools_list_size`.
10. Every public item documented (`#![deny(missing_docs)]` as in the crate), no `unwrap`/`expect`/`panic` outside tests, `// spec:` markers name spec ids only (CMP-*, SEC-*, GQL-*, INV-*), never ADR ids.

## 4. Tests (binding)

* **No sockets, no child processes**: the HTTP path is driven by calling `HttpModule::handle` directly; stdio through `tokio::io::duplex`. A scripted `FakeEngine` (records requests, returns canned `GraphqlResponse`s, optional `panic` variant) and real composed snapshots via `gap_snapshot` (two small branches incl. a T2 branch and an N-branch generator). One `#[ignore = "needs child process"]` test is **not** required.
* Wire matrix: every CMP-001 rule one test each (missing `_meta` keys, unsupported version `-32022` with the list, header mismatches `-32020` incl. a hostile `Mcp-Method` that differs from the body, wrong `Accept`, `405`, `403` origin, oversize body, batch refused, malformed JSON, unknown method), `server/discover`, legacy `initialize` -> session -> `tools/list` -> unknown session `404` -> eviction at `max_sessions` and at idle TTL (paused time), stdio framing (partial lines, two requests in one write, oversized line, EOF).
* Tools: schema of each tool equals the contract table (compare against a fixture `conformance/mcp/tools.expected.json` written **from spec/09, not from the code**), strict argument validation matrix, `tools/list` identical across principals and connections, `gap_query` read-only enforcement (mutation, subscription, `gap { submitTask }` all refused before the engine), `gap_mutate` forwarding (dry run, idempotency key, `input_required`), `gap_task` actions and the `tasks:decide` scope, budget truncation incl. a multi-byte boundary, `isError` rules, errors preserved.
* Discovery: overview ordering and caps, types expansion depth 1..3 on a cyclic schema, hidden elements absent everywhere with `HideT2` (compare the whole output with and without the T2 branch: byte-identical), search baseline vs a fake `ElementSearch` with elements, abstention, truncation comment, `GAP_DISCOVERY_DEGRADED` marker.
* Spotlighting: T2 root field wrapped, T0 not, `spotlight=false`, the forged-closing-tag payload, provenance list.
* Size gate (3.9) incl. each description alone. Interleaved stateless requests: 200 concurrent mixed requests over one facade (paused time + `join_all`) each answered with its own id and its own pinned snapshot generation (two generations published during the run).
* **Conformance fixtures** `conformance/mcp/*.json` (>= 12; the format of section 7) covering CMP-001..CMP-008, executed by `tests/inbound/conformance.rs` (test name contains `conformance_facade_mcp`); each fixture was derived from the spec text, not by recording the implementation.
* Every test carries `// spec: <ID>`; deterministic; 3 runs without flakiness.
