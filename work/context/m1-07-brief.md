## 3. Design (binding shape; names inside a module are yours unless stated)

1. **`connector_layer`**: an object-safe client trait `BranchClient: Send + Sync + 'static` with `fn query(&self, request: QueryRequest, scope: CallScope) -> Pin<Box<dyn Future<Output = NgcResult<BoxStream<QueryResponse>>> + Send + '_>>` (boxed future: the SDK `Connector` trait is generic/RPITIT and not dyn-compatible), implemented for `gap_ngc_sdk::grpc::GrpcClient` and an adapter `InProcess<C: Connector>` over the SDK server core for tests.
   `ConnectorRegistry` = immutable `BTreeMap<BranchUid, Arc<dyn BranchClient>>` built before serving (INV-02: no lock on the read path); "pooling" in v0 means one multiplexed client per branch (document it). Per-branch bulkhead: a `tokio::sync::Semaphore` of `BranchDescriptor.limits.max_in_flight`, acquired with `try_acquire` (a saturated branch fails that fetch with `GAP_OVERLOADED`-class error, never queues).
2. **`ExecLayer`** (`exec` module) implements `tower::Service<ExecRequest, Response = ExecResponse, Error = Infallible>` (RUN-001); `ExecRequest { snapshot: Arc<Snapshot>, plan: Arc<Plan>, variables: serde_json::Map, deadline: tokio::time::Instant, cancel: CancellationToken, limits: ExecLimits }` with `ExecLimits { max_parallel_fetches (8), max_response_bytes, margin_floor (50 ms), margin_fraction (5%) }`;
   `ExecResponse { data: Option<serde_json::Value>, errors: Vec<GraphqlError>, extensions: GapExtensions { generation, cost, partial } }` (`GQL-050/051`). The snapshot is pinned by the request (INV-01): the executor never re-reads a handle.
3. **Execution** (RUN-015/030/031): `Fetch` -> one connector `Query` for that root field; `Parallel` -> concurrent, bounded by `max_parallel_fetches`; `Sequence` -> in order. Per call `deadline = min(request.deadline - margin, now + branch.limits.timeout_ms)` with `margin = max(margin_floor, margin_fraction * remaining)`, sent as `CallContext.deadline_unix_ms` (derive it from the wall clock through the injected `gap_core::Clock`) and as the `CallScope` deadline; an already expired deadline fails `GAP_DEADLINE_EXCEEDED` without calling the connector.
   Cancellation: a child `CancellationToken` per call; cancelling the request drops every in-flight stream within 50 ms (the SDK client sends the gRPC cancel on drop), nothing keeps running after the response is returned. `ArgValue::Variable` is bound from `variables` (missing required variable -> `GAP_VALIDATION_ERROR`), `@skip`/`@include` are evaluated per fetch and per selection field.
4. **Assembly** (RUN-060, GQL-051): rows -> JSON by the root field's schema type (list -> array of projected rows, object -> first row or `null`, scalar/JSON -> as is); projection by `Fetch.selection` (aliases, `__typename` = the schema type name, nested objects, fields absent from a row become `null` only when the schema type is nullable, otherwise it is a non-null violation).
   GraphQL error propagation: a failed fetch yields `null` at its response key plus one `errors[]` entry `{message, path, extensions: {code}}`; a non-null violation nulls the nearest nullable ancestor (top level included: `data: null`); `partial = true` whenever `data` is present and at least one error was recorded. The response size is tracked **while assembling**: past `max_response_bytes` assembly stops and the answer is `GAP_RESPONSE_TOO_LARGE` naming the truncation point (field path), without building the full body first.
5. Error mapping from NGC (`NgcErrorInfo`) to GAP codes: table in the crate docs and tested for every `NgcErrorCode`; connector text is sanitised and clipped (INV-15: never a credential), details dropped.
6. Crate header as the other crates; the existing placeholder modules (`bulkhead`, `columnar`, `join`, `mutate`, `saga`, `shadow`, `tasks`, `traverse`) stay.

## 4. Tests (binding)

* End to end with a real `gap_plan::plan` over a hand-built two-branch `Snapshot` and branches served by `gap_ngc_sdk::mock::MockConnector` through `in_memory_grpc` (no sockets): data, aliases, `__typename`, nested projection, list vs object, variables, `@skip`/`@include`, two branches in parallel, one failing branch (partial), all branches failing (`data: null`).
* Deadline reaches the connector (the connector observes `deadline_unix_ms` and `CallScope.deadline` equal to the RUN-030 formula for three remaining-time cases, including the 5% margin and the 50 ms floor); an expired deadline never calls the connector.
* Cancel within 50 ms (paused time): request cancel drops the in-flight stream and the connector observes the drop (the mock's drop guard); an executor future dropped by the caller does the same; no task outlives the response (check the connector's in-flight counter returns to 0).
* Error/null propagation matrix (nullable vs non-null field, list items, nested objects, top level) with golden JSON for each cell; `NgcErrorCode` -> GAP code table (all 14); error text never contains a canary credential.
* Bounds: `max_parallel_fetches` observed concurrency never above the cap and reaches it; per-branch bulkhead saturation fails fast with the overload code; `max_response_bytes` stops assembly early (assert the number of rows touched), exact-fit boundary (equal to the cap passes, one byte more fails).
* `ExecLayer` through `tower::ServiceExt::oneshot`; the snapshot pinned by the request is the one answered even if a new generation is published meanwhile (INV-01, two generations, content compared).
* Every test carries `// spec: <ID>` (RUN-001, RUN-015, RUN-024, RUN-030, RUN-031, RUN-060, GQL-050, GQL-051, INV-01, INV-02, INV-12, INV-15); deterministic (paused time), 3 runs without flakiness.
