### CG-01 — Normative visibility, lifecycle, and GAP-QL surface for `ContextStore` scopes (`Private | Task | Group | Global | Ephemeral`)

However, `@scope` was removed from `spec/02-gap-ql.md` §5, neither `TraverseInput` (`spec/02-gap-ql.md:85-92`) nor `GapNode` (`spec/02-gap-ql.md:99-103`) includes a `scope` field, and no `spec/*.md` defines principal ownership (`Private` vs `Group`), `Task` scope binding/cleanup on task completion, `Ephemeral` TTL eviction, or how scoped memory nodes are written.
- **Why it matters:** Under `.agent/rules/gap-protocol.md` Rule 1 (*"Never implement behaviour that no spec/ADR covers; record the gap"*), `WP-M2-01` cannot implement a conformant `ContextStore` trait suite without guessing access-control and TTL semantics, risking intra-tenant data leakage between principals or tasks.

### CG-02 — Missing NGC wire field for per-response rate-limit capacity hints (`CMP-033` vs `ngc.proto` / `RTE-073`)
- **Evidence:**
  - Old session: `graph-agent-protocol-plan.md:221,307` and `gap-agent-spec-and-skill.md:102` (`X-RateLimit-*` fed into branch `capacity_hint`).
  - Current repo: `spec/09-compat.md:47` (`CMP-033`) mandates that `gap-ngc-openapi` *"MUST ... feed rate-limit headers (`X-RateLimit-Remaining`) into telemetry as capacity hints"*, and `work/work-packages.toml:346,350` (`WP-M1-11`) tests `CMP-033` with a REST fixture emitting rate-limit headers. Yet `proto/gap/ngc/v1/ngc.proto` has no capacity-hint field on `Complete` (lines `209-215`) or `MutateResponse` (lines `239-246`), and `spec/04-routing.md:107` (`RTE-073`) only reads `capacity_weight` from `Health` details (`ngc.proto:319`, polled every 5 s in `WP-M3-04`) without specifying a canonical key name or normalization formula.
- **Why it matters:** Out-of-process NGC connectors (`gRPC`, `HTTP`, `stdio`) cannot transmit per-call `X-RateLimit-Remaining` signals back to the gateway's `TelemetrySlot` unless the NGC wire contract carries them (or `HealthResponse.details` defines a canonical key); furthermore, `WP-M0-06` freezes a SHA-256 golden test on `ngc.proto`'s `FileDescriptorSet`.

### CG-03 — Underspecified edge-cost source and tie-breaking for `TraverseStrategy::WEIGHTED`
